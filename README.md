## 核心规则

1. **时效性**：优先选择24小时以内发生的最新事件
2. **信息来源**：采用主流权威媒体
3. **全局去重**：14个板块之间严禁出现重复新闻
4. **先搜索再写作**：每条新闻必须先 web_search 搜索验证
5. **AI智能分析**：每条新闻包含200-250字的AI分析
