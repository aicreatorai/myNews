## 📝 输出格式

> ⚠️ **每条 ≈1000 字**（控制在 900-1100 字）。本模块核心价值是"让读者看完就能用起来"。严禁功能介绍式罗列。

```markdown
### 1. 【工具名+核心价值一句话】（不超过35字）

> 📍 **导语**（100-120字）: 用2-3段交代这是什么工具、解决什么痛点、和同类比好在哪、为什么今天值得学（最近有什么新功能/更新）。让读者看完开头就想立即尝试。

---

**🛠 深度实操指南**

**▌ 工具速览**（100-150字）
一句话说清这个工具是做什么的。开发者/团队背景（信誉背书）。收费模式（免费版范围/付费版价格/限免情况）。用户规模/评分（如有数据）。一句话说清"为什么不用A而用你"。

**▌ 核心功能场景化拆解**（150-200字）
按场景组织功能，不是罗列功能清单。每个场景写清：做什么用 → 工具怎么解决 → 效果如何。突出最让人WOW的功能：这个工具有什么功能是竞品没有或做得明显更好的。

**▌ 实战工作流**（250-350字，本模块核心价值）
不从功能角度讲，而是**从一个真实任务出发，完整走一遍流程**：

```
场景：假设你要[一个真实任务]
Step 1: 打开工具 → 具体操作
Step 2: 输入什么 → 完整的提示词/配置/参数
Step 3: 工具的响应 → 怎么判断输出质量
Step 4: 发现问题怎么调整 → 迭代优化技巧
Step 5: 最终成果 → 完成的任务长什么样
关键心得：做这个任务比手动做快了多少、好在哪
```

**▌ 进阶技巧**（80-120字，选填但推荐）
80%的人不知道的功能、效率翻倍的快捷键/配置、与其他工具组合使用的最佳实践。

**▌ 选型对比**
| 决策维度 | 用这个工具 | 用竞品A | 用竞品B |
|---------|----------|--------|--------|
| 适合什么任务 | | | |
| 不适合什么任务 | | | |
| 学习成本 | | | |
| 价格 | | | |

---

🔗 **信息来源：** 工具官方文档（更新日期）/ 媒体评测（发布日期）/ 用户测评（发布日期）
每条至少 2 个独立来源，优先工具官网/官方博客/少数派/AppSo/Product Hunt
```
