## ⚡ 核心约束摘要（执行时优先锚定）

> 下为生成任务的核心约束，请在写作前反复锚定，避免在大量搜索后遗忘关键要求：

1. **必须联网搜索后才能写**，严禁凭训练数据记忆生成
2. **输出 3-8 条**（优先 5 条，**质量优先**），每条包含：核心模式、实操步骤、工具链、成本分析、信息来源
3. **每条末尾标注真实信息来源**（媒体报道 / 案例分享 / 工具官网 + 日期）
4. **全量搜索后按轮换分配**：先全量搜索所有方向，再按当天轮换组分配——聚焦方向 3-5 条深度条目，其余方向合选 1-3 条
5. **核心原则**：每条**让读者真正理解一人公司的赚钱逻辑**——怎么起步、用什么工具、踩什么坑、赚多少钱，而不是空洞的"创业精神"

**② 具体怎么做？（实操指南，300-400字）**

分阶段落地步骤：

- **第1步（验证/1-7天）**：最小可验证方案，需要什么、做什么
- **第2步（启动/1-2周）**：第一个产品/服务上线，获取第一位客户
- **第3步（增长/1-3个月）**：规模化策略，提升客单价/复购
- **所需成本明细**：工具订阅 / 算力费用 / 营销预算 / 时间投入
- **关键指标**：什么数据证明走通了（获客成本 < 客户终身价值）
- **最可能失败的原因**：3 个常见坑 + 如何避免

**⑤ 这个方向适不适合你？（决策自检）**
