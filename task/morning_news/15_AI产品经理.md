## 📝 输出格式

> ⚠️ **每条 800-2500 字**（优先 1500 字左右，内容丰富则不限）。本模块核心价值是"让读者真正理解这个产品方法论为什么有效"。

```markdown
### 1. 【标题】（不超过35字，点明方法论名+核心价值+适用场景，如「数据飞轮：ChatGPT如何用用户反馈驱动模型迭代」）

> 📍 **导语**（100-160字）: 用2-3段交代这个方法/案例是什么、解决什么产品问题、为什么AI PM今天必须掌握、能带来什么实际改变。

---

**📋 深度产品分析**

**▌ 核心指标速览**（100-200字）
先列出最核心的几个产品数据，让读者30秒掌握全貌：DAU/留存率/转化率/收入/NPS等硬指标。可用要点式呈现。

**▌ 这个方法/案例是什么？**（150-250字）
一句话定义。适用场景——什么产品阶段/团队规模/问题类型。常见误区——新手PM最容易踩的坑。和传统PM方法的本质区别——AI时代新在哪（数据飞轮/模型迭代/不确定性管理/用户预期管理）。

**▌ 为什么有效？（底层产品逻辑，400-600字，本模块核心价值）**
**这是最重要的部分**。这个方法利用了AI产品的什么特性？（数据飞轮效应/模型能力边界/用户预期管理/网络效应）？决策框架——怎么判断"什么时候用这个方法、什么时候不用"？关键数据支撑——引用真实产品数据（"采用此策略的产品次周留存提升23%"）。失败的场景——什么情况下照搬这个方法会挂掉，为什么？

**▌ 具体怎么落地？（实操指南，300-600字）**
分步骤的落地操作指南。第一步（定义/准备）：理清输入条件、确定评估标准。第二步（执行核心动作）：具体操作步骤。第三步（验证/迭代）：怎么判断做对了、怎么优化。产出物示例：PRD片段/数据看板/用户调研提纲。

**▌ 真实产品案例（必填）**
| 维度 | 案例详情 |
|:----|:---------|
| 产品名称 | xxx |
| 问题背景 | 什么场景下用了这个方法 |
| 执行过程 | 怎么做的 |
| 结果数据 | DAU/留存/收入/NPS等硬指标变化 |
| 关键启示 | 教会我们什么 |
> 国内AI产品案例优先（豆包/通义/文心/Kimi等）。如为海外案例需附带国内落地分析。

**▌ 对比分析**

|---------|--------|---------|-----------|
| 核心逻辑 | | | |
| 适合场景 | | | |
| 投入成本 | | | |
| 见效周期 | | | |
| 最大风险 | | | |

**▌ 今天就做的一件事**（100-200字）
读者看完后现在立刻能做的行动。具体动作（如"打开你的产品后台，找到最近7天的用户留存数据"）。预计耗时。做完后能得到什么洞察。
```
