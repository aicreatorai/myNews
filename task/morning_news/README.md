## 📌 使用说明

1. **通用模板**：所有文件基于 `任务基础模板.md` 的通用规范，每个文件仅包含差异化内容
2. **执行顺序**：分 3 批执行（详见 `并行新闻生成配置.md`）：
   - 第一批（综合新闻）：01、02、03、04、06
   - 第二批（科技开发）：05、07、08、09、10
   - 第三批（知识沉淀）：11、12、13、14、15
3. **输出目录**：`news/{YYYYMM}/{YYYYMMDD}/`，每个模块输出对应编号文件
4. **去重规则**：
   - 知识类模块（07/08/09/10/12/13/14/15）适用时序去重，通过 `knowledge-index-{模块编号}.json` 管理
   - 通用跨模块去重规则见 `任务基础模板.md`
5. **日期变量**：执行时替换 `{DATE}`、`{DATE-1}`、`{YYYYMM}`、`{YYYYMMDD}` 等占位符
