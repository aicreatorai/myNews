## 📌 使用说明

1. **通用模板**：所有文件基于 `任务基础模板.md` 的通用规范
2. **执行分组**：
   - **第一批（新闻快讯）**：01
   - **第二批（技术前沿+工具）**：02、03、04、05、06、07、08、09
   - **第三批（知识+社区）**：10、11、12、13、14、15
3. **输出目录**：`news/{YYYYMM}/{YYYYMMDD}/`
4. **去重规则**：知识类模块（02/03/04/07/08/09/12/13/14/15）适用时序去重
5. **日期变量**：执行时替换 `{DATE}`、`{DATE-7}`、`{YYYYMM}` 等占位符
