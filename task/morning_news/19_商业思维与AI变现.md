**① 这是什么商业模式？（200-300字）**

- 一句话定义：用最直白的话说清楚这个方案怎么赚钱
- 核心公式：`收入 = 流量 × 转化率 × 客单价` 或等价的财务模型
- 收入模型：卖什么（产品/服务/订阅/广告/佣金/API调用...）
- 成本结构：固定成本 + 变动成本 + AI 相关成本（API费/算力等）
- 利润空间：毛利率/净利率/回本周期
- 护城河：为什么别人不能轻易复制

**② 为什么现在能跑通？（市场逻辑分析，300-400字，重点！）**

这是全文最重要的部分，必须讲清楚商业逻辑背后的驱动因素：

- **市场驱动力**：什么变化让这个模式现在可行？（技术成熟/用户习惯/政策开放/成本下降...）
- **时机分析**：为什么一年前不行、一年后可能太晚
- **竞争格局**：当前有哪些玩家、各自的核心差异
- **市场规模**：TAM（总可用市场）/ SAM（可服务市场）/ SOM（可获得市场），引用真实行业数据
- **关键假设**：这个模式成立的前提条件是什么——如果条件不满足会怎样

**③ 具体怎么落地？（实操指南，300-400字）**

从零到一的实施路径：

- **第一阶段（验证/1-2周）**：最小可行性验证，需要什么资源、做什么
- **第二阶段（启动/1个月）**：核心执行动作、获取第一批用户/客户
- **第三阶段（增长/1-3个月）**：规模化策略、关键里程碑
- **第四阶段（优化）**：提升转化率/客单价/复购率
- **所需成本**：启动资金 / 时间 / 人力
- **关键指标**：什么数据证明模式跑通了（如获客成本 < 用户LTV）
- **风险点与应对**：3 个最可能失败的原因 + 怎么预防

**④ 真实案例拆解（必填，要求数据）**

选择一个真实案例（国内优先），详细拆解：

| 维度 | 案例详情 |
|------|---------|
| 案例名称 | xxx（公司/个人） |
| 启动时间 | xxx |
| 前期投入 | xxx 元/时间 |

| 成本明细 | API费/人力/营销等 |
| 净利润 | xxx 元/月 |
| 关键成功因素 | 做对了什么 |
| 踩过的坑 | 做错了什么 / 损失了多少 |

如果没有完整的财务数据，至少写 2-3 个微型案例横向对比。
