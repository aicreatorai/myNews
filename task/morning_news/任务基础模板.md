# 早间新闻生成任务基础模板

> 本文件为所有 15 个任务文件的通用规范，每个任务文件仅需包含差异化内容（搜索关键词、条数、去重要求等）。

---

## ⚡ 核心约束

1. **必须联网搜索后才能写**，严禁凭训练数据记忆生成
2. **全量搜索原则**：每个子领域的所有关键词必须逐一执行，不得跳跃
3. **核实关键数据**：数字类信息必须通过第二次搜索确认
4. **信息来源必填**：每条末尾标注真实来源（媒体名称 + 报道日期）
5. **禁止套话**：不使用"具有重要意义"等空洞表述，用事实和数据说话

---

## 🚀 双阶段执行流程

### 第一阶段：搜索记录
逐条执行所有关键词，每条搜索结果写入 scratchpad：
```
[关键词] → 核心信息: [时间+主体+关键数据] | 来源: [URL]
```

### 第二阶段：写作输出
基于 scratchpad 笔记逐条撰写，每条必须引用真实来源

---

## 📝 通用输出格式

### 文件头部
```markdown
# XX_模块名称

> **生成日期**：{DATE} | **搜索时段**：{DATE-1} 07:00 ~ {DATE} 07:00
> **总条数**：N 条
```

### 每条新闻结构
```markdown
### N. 【标题】（不超过35字）
> 📍 导语（50字以内）
---
[深度报道内容]
---
🤖 AI深度研判（可选）
---
🔗 信息来源：媒体（日期）
```

### 标题格式
- 不超过 35 字
- 必须包含核心信息（主体+动作+数据）

---

## 📋 执行参数

| 参数 | 格式 | 示例 |
|------|------|------|
| `{DATE}` | YYYY-MM-DD | 2026-05-14 |
| `{DATE-1}` | YYYY-MM-DD | 2026-05-13 |
| `{DATE-7}` | YYYY-MM-DD | 2026-05-07 |
| `{YYYYMM}` | YYYYMM | 202605 |
| `{YYYYMMDD}` | YYYYMMDD | 20260514 |
| **输出路径** | `news/{YYYYMM}/{YYYYMMDD}/` | `news/202605/20260514/` |

## 🔑 通用跨模块去重规则

| 事件类型 | 归属模块 | 其他模块切入角度 |
|---------|---------|----------------|
| 商业/公司动态 | 06_科技动态 | 05→只谈技术原理，不谈商业 |
| 学术/技术突破 | 05_科技前沿 | 06→只谈行业影响，不谈技术 |
| AI开发工具/框架 | 10_GitHubSkills | 08→只谈使用体验，不谈代码 |
| 语言版本发布 | 09_开发语言 | 11→只谈该语言在本生态的影响 |
| 移动端开发技术 | 11_移动开发 | 05→只谈底层AI技术，不谈框架 |
| AI商业变现/创业 | 12_AI创业 | 05→只谈技术突破不谈商业 |
| AI+教育 | 13_AI教育 | 05→只谈技术不谈教育场景 |
| 个人提升 | 14_个人成长 | 12→只谈赚钱不谈个人成长 |
| AI产品管理 | 15_AI产品经理 | 05→只谈技术不谈产品 |
| 一人公司创业 | 12_AI创业 | 08→只谈工具不谈模式 |

> **执行原则**：写作前自查事件类型，切入角度必须与归属模块不同。

## 🌐 来源优先级

1. **第一梯队**：新华网、人民日报、央视新闻、中国政府网
2. **第二梯队**：财新网、第一财经、经济观察报、澎湃新闻
3. **第三梯队**：Reuters、BBC、Financial Times、AP

---

## 🚫 通用禁止行为

1. 禁止凭记忆生成内容
2. 禁止编造数据
3. 禁止虚假来源
4. 禁止跳过搜索步骤
5. 禁止内容缺失

---

## ⏰ 搜索时段

> ⚠️ 各模块搜索窗口不同，以单个任务文件中的「搜索时段」为准。以下为通用参考：
- **新闻类模块**（01/02/03/04）：24小时
- **科技类模块**（05/06/11）：3-7天
- **知识类模块**（07/08/09/10/12/13/14/15）：7-30天

```
"[子领域名称] site:媒体域名 {DATE-1}至{DATE}"
```
