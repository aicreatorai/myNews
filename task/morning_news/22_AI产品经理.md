**① 这个方法/案例是什么？（核心概念，200-300字）**

- 一句话定义
- 适用场景：什么产品阶段/团队规模/问题类型
- 常见误区：新手 PM 最容易踩的坑
- 和传统 PM 方法的本质区别（AI 时代新在哪）

**② 为什么有效？（底层产品逻辑，300-400字，重点！）**

这是全文最重要的部分，必须讲清楚方法论背后的逻辑：

- **产品逻辑拆解**：这个方法利用了 AI 产品的什么特性？（如：数据飞轮效应、模型能力边界、用户预期管理）
- **决策框架**：怎么判断"什么时候用这个方法、什么时候不用"
- **关键数据支撑**：引用真实产品数据（如"采用此策略的产品，次周留存提升 23%"）
- **失败的场景**：什么情况下照搬这个方法会挂掉，为什么

**③ 具体怎么落地？（实操指南，300-400字）**

分步骤的落地操作指南：

- **第一步（定义/准备）**：理清输入条件、确定评估标准
- **第二步（执行核心动作）**：具体操作步骤
- **第三步（验证/迭代）**：怎么判断做对了、怎么优化
- **产出物示例**：PRD 片段 / 数据看板 / 用户调研提纲

**④ 真实产品案例（必填，要求数据）**

选择一个真实的 AI 产品（国内优先），拆解：

| 维度 | 案例详情 |
|------|---------|
| 产品名称 | xxx |
| 问题背景 | 什么场景下用了这个方法 |
| 执行过程 | 怎么做的（按步骤对应③） |
| 结果数据 | DAU/留存/收入/NPS 等硬指标变化 |
| 关键启示 | 这个案例教会我们什么 |

如果当天搜索不到足够完整的数据案例，至少写 2-3 个微型案例横向对比。

**⑤ 和其他方法比有什么不同？（对比分析）**

| 投入成本 | | | |

| 最大风险 | | | |

**⑥ 今天就做的一件事（最小行动）**
