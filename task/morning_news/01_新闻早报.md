# 01_新闻早报（TOP 12-18条）

> 由 01_今日头条 + 02_国内热点 + 03_国际视野 + 04_财经市场 **合并统一版**。
> 基于 `任务基础模板.md` | 本文件仅包含差异化内容

---

## ⚡ 核心约束

1. **必须联网搜索后才能写**，严禁凭训练数据记忆生成
2. **输出 12-18 条**（优先 14-16 条），500-700字/条
3. **每条末尾标注真实信息来源**（至少1个独立来源）
4. **零重复原则**：同一事件/数据/新闻在全文中只出现一次
5. ⚠️ **全量搜索**：每个关键词逐一执行，不得跳跃
6. ⚠️ **安全检测规避**：政治/法治/国防类若触发检测，**跳过**继续

## 📋 任务参数

| 项目 | 内容 |
|------|------|
| **输出文件** | `news/{YYYYMM}/{YYYYMMDD}/01_今日头条.md` |
| **文件内标题** | `# 新闻早报` |
| **新闻条数** | 12-18 条，覆盖下方四大领域 |
| **搜索时段** | `{DATE-1} 07:00 ~ {DATE} 07:00`（24小时） |

### 四大领域条数分配

| 领域 | 定位 | 条数 |
|:----|:-----|:----:|
| **头条** | 当日最重要事件（政治/经济/国际大事件） | 3-4条 |
| **国内** | 政策法规、民生实事、社会热点 | 3-5条 |
| **国际** | 地缘政治、国际组织、区域热点 | 3-4条 |
| **财经** | 股市、央行、企业财报、大宗商品 | 3-5条 |

## 🚫 去重规则（事件归属表）

重大事件只能进入一个领域，写作过程中逐条自查，发现重复立即替换：

| 事件类型 | 归属 | 其他领域 |
|---------|:----:|:--------:|
| 中美元首会晤、重大外交行动 | 头条 | 国际/财经→跳过 |
| CPI/PPI、GDP经济数据 | 头条 | 国内/财经→跳过 |
| 科技重大突破（航天/芯片） | 头条 | 其余→跳过 |
| 国内政策法规、民生数据 | 国内 | 头条→跳过 |
| 地缘冲突（俄乌/中东） | 国际 | 头条→跳过 |
| 美联储利率、央行降准 | 财经 | 头条→跳过 |
| 股市数据、大宗商品行情 | 财经 | 其余→跳过 |

## 📝 统一输出格式

所有文章使用**同一模板**，通过标题前的 `[标签]` 区分领域。严格控制在500-700字。

```markdown
# 新闻早报

> **生成日期**：{DATE} | **搜索时段**：{DATE-1} 07:00 ~ {DATE} 07:00
> **总条数**：N 条

---

### 1. [头条] 标题（不超过30字，点明事件+关键数据）

> 📍 **导语**（60-80字）: Who/What/When + 最核心的一个数据，30秒知全貌。

**核心信息**（250-300字）
- 事件还原：时间、主体、行为、结果，附具体数据
- 背景速览：为何此刻发生/历史铺垫（一两句）
- 各方声音：官方表态、市场反应、专家解读（各一句）

**判断**（100-150字）
- 短期影响 + 中长期影响
- 一句话本质判断：这件事改变了什么

🔗 **来源：** 媒体1（日期）/ 媒体2（日期）

### 2. [国内] 标题

> 📍 **导语**（60-80字）: 政策主体+核心内容+关键数据。

**核心信息**（250-300字）
- 事件全景：完整叙事，引用官方表述，量化数据
- 来龙去脉：政策背景或社会动因（一两句）
- 各方声音：官方+专家+民众，各一句

**判断**（100-150字）
- 短期+中长期影响
- 对普通人/企业的建议（一句话）

🔗 **来源：** 媒体1（日期）

### 3. [国际] 标题

> 📍 **导语**（60-80字）: 事件+国家+最新进展+对华关联。

**核心信息**（250-300字）
- 事件全景：时间、地点、主体、核心事实
- 各方博弈：主要力量表态和利益诉求
- **中国视角**（80-100字，必填）：事件对中国的直接或间接影响

**判断**（100-150字）
- 走向预判（1-3个月最可能方向）
- 对华影响评级（1-5星）及理由

🔗 **来源：** 媒体1（日期）

### 4. [财经] 标题

> 📍 **导语**（60-80字）: 市场/资产+核心数据+变动原因+对投资者的意义。

| 指标 | 最新值 | 涨跌幅 |
|------|--------|:------:|
| 上证指数 | XXXX.XX | +X.XX% |

**分析**（250-300字）
- 驱动因素：主因+次因，核心矛盾
- 市场情绪：资金流向/成交量/恐慌指数

**判断**（100-150字）
- 短期展望（1-2周）
- 关键变量：什么要素可能打破趋势

🔗 **来源：** 媒体1（日期）/ 数据平台

### 5-18. ...（同上格式，按 头条→国内→国际→财经 顺序输出）
```
