# 01_新闻早报（TOP 8-12条）

> 覆盖今日头条、国内热点、国际视野、财经市场四大领域。
> 基于 `任务基础模板.md` | 本文件仅包含差异化内容

---

## ⚡ 核心约束

1. **必须联网搜索后才能写**，严禁凭训练数据记忆生成
2. **输出 6-8 条**，**800字左右/条**
3. **每条末尾标注真实信息来源**（至少1个独立来源）
4. **零重复原则**：同一事件/数据/新闻在全文中只出现一次
5. ⚠️ **全量搜索**：每个关键词逐一执行，不得跳跃

---

## 🚫 去重规则

1. **内容级去重**：写作前运行 `check-dedup.py check "<标题>"`，返回 🔴 则跳过
2. **内部零重复**：同一内容在全文中只出现一次
3. **跨领域不重复**：同一内容不进入国内/国际/财经板块

---

## 📋 任务参数

| 项目 | 内容 |
|------|------|
| **输出文件** | `news/{YYYYMM}/{YYYYMMDD}/01_今日头条.md` |
| **文件内标题** | `# 新闻早报` |
| **新闻条数** | 6-8 条，覆盖四大领域 |
| **输出顺序** | 先写头条 → 再国内 → 再国际 → 最后财经，**同领域内按重要性降序** |
| **搜索时段** | `{DATE-1} 07:00 ~ {DATE} 07:00`（24小时） |

### 四大领域条数分配

| 领域 | 定位 | 条数 |
|:----|:-----|:----:|
| **头条** | 当日最重要事件（经济/科技/国际大事件） | 2-3条 |
| **国内** | 政策法规、民生实事、社会热点 | 2-4条 |
| **国际** | 国际关系、国际组织、区域合作 | 2-4条 |
| **财经** | 股市、央行、企业财报、大宗商品 | 2-4条 |

重大事件只能进入一个领域，写作中逐条自查，发现重复立即替换：

| 事件类型 | 归属 | 其他领域 |
|---------|:----:|:--------:|
| CPI/PPI、GDP经济数据 | 头条 | 国内/财经→跳过 |
| 科技重大突破（航天/芯片/AI） | 头条 | 其余→跳过 |
| 国内政策法规、民生数据 | 国内 | 头条→跳过 |
| 国际组织重大决议、区域合作 | 国际 | 头条→跳过 |
| 美联储利率、央行降准 | 财经 | 头条→跳过 |
| 股市数据、大宗商品行情 | 财经 | 其余→跳过 |

## 📝 统一输出格式

所有文章使用**同一模板**，通过 `[标签]` 区分领域。严格500-700字。

```markdown
# 新闻早报

> **生成日期**：{DATE} | **搜索时段**：{DATE-1} 07:00 ~ {DATE} 07:00
> **总条数**：N 条

---

### 1. [头条] 标题（不超过30字，点明事件+关键数据）

> 📍 **导语**（100-120字）: Who/What/When + 最核心的一个数据，30秒知全貌。

**核心信息**（400-450字）
- 事件还原：时间、主体、行为、结果，附具体数据
- 背景速览：为何此刻发生/历史铺垫（一两句）
- 各方声音：官方表态、市场反应、专家解读（各一句）

**判断**（150-200字）
- 短期影响(1-3月) + 中长期影响
- 一句话本质判断：这件事改变了什么

🔗 **来源：** 媒体1（报道日期）/ 媒体2（报道日期）
```
> **补充要求**：
> - **[国际]** 核心信息中必填 **全球影响**（80-100字）：事件对全球经济和国际合作的直接或间接影响
> - **[财经]** 核心信息前插入**关键数据表**；判断**替换为**：短期展望(1-2周) + 关键变量（什么数据可能打破趋势）

### 关键数据表格式（仅财经）
```
| 指标 | 最新值 | 涨跌幅 |
|------|--------|:------:|
| 上证指数 | XXXX.XX | +X.XX% |
```

### 输出示例（循环使用）

```
文章1. [头条] ...
文章2. [头条] ...
文章3. [国内] ...
文章4. [国内] ...
文章5. [国内] ...
文章6. [国际] ...
文章7. [国际] ...
文章8. [财经] ...
文章9. [财经] ...
文章10. [财经] ...
```

编号全局连续，标签决定内容格式。同领域按**重要性降序**排列。

## 🚫 禁止行为

1. 禁止"旧闻当新闻"（头条须在24小时内）

3. 禁止缺少数据支撑（国内/财经必须有量化数据）
4. 禁止国际板块缺少中国视角
5. 禁止超字数（800字左右，±50字）
6. 禁止跳过搜索步骤
