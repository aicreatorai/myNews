> - 日期变量由自动化系统在每次执行时填充
> - 输出路径自动根据日期生成
> - 适用于每日自动执行或手动指定日期执行

## ⚡ 核心约束摘要（执行时优先锚定）

> 下为生成任务的核心约束，请在写作前反复锚定，避免在大量搜索后遗忘关键要求：

1. **必须联网搜索后才能写**，严禁凭训练数据记忆生成
2. **输出 5-12 条**（优先 8 条，**质量优先**），每条包含：核心概念、原理分析、操作指南、案例对比、信息来源
3. **每条末尾标注真实信息来源**（媒体报道 / 书籍/课程 / 博客 / 工具官网 + 日期）
4. **全量搜索后按轮换分配**：先全量搜索所有方向，再按当天轮换组分配——聚焦方向 6-8 条，其余方向合选 2-4 条
5. **核心原则**：每条**让读者真正学到知识**——读完既理解原理，又知道怎么用。不做鸡汤，不做空洞步骤堆砌

> **先搜索→记笔记→再写作**，全程两个阶段不交叉。

### 第一阶段：搜索记录
逐条执行所有关键词，每条搜索结果写入 scratchpad：
```
[关键词] → 来源: [URL] | 核心信息: [提升方向+具体方法+关键技巧/数据]
```

### 第二阶段：写作输出
基于 scratchpad 笔记逐条撰写，每条必须引用真实来源

```

> 📍 **导语**：用 1-2 句话说清楚这个方法是什么、解决什么实际问题、为什么今天值得认真学。要让读者看完开头就感受到"这个我必须了解"。

**① 这个方法是什么？（核心概念，200-300字）**

用直白的话完整定义这个方法/概念。至少包含：
- 一句话定义
- 它和普通人直觉认知的差异（常见误区）
- 它的起源/提出者/背景故事（有出处）
- 适合谁、不适合谁

**② 它为什么有效？（底层原理，300-400字，本模块知识价值的核心）**

这是全文最重要的部分，必须讲清楚方法背后的原理：

- **认知科学/心理学基础**：这个方法利用了大脑的什么机制？（如：间隔效应、多巴胺奖励机制、认知负荷理论等）
- **类比解释**：用一个生活化的比喻帮助理解
- **关键数据/研究支撑**：引用具体的研究数据（如"研究发现，使用该方法的组比对照组效率提升 37%"）
- **为什么大多数人做错了**：指出常见的理解和执行误区

**③ 具体怎么做？（可执行指南，300-400字）**

分步骤的操作指南，每步必须具体到"什么时间做什么"：

- **第一步（准备/5分钟）**：最先要做的事，5分钟内可完成
- **第二步（执行/30分钟）**：核心执行步骤，今天可以完成
- **第三步（坚持/本周）**：如何持续做下去，建立习惯
- **进阶技巧**：如果基础版已经熟练，如何升级

**④ 真实案例与效果**

- 至少一个真实的成功案例（人名+背景+具体做法+结果数据）
- 如果没有案例，用"假设场景"模拟：一个典型的读者从0到1的执行全过程
- 量化效果（如"每天投入30分钟，2周后效率提升50%"）
- 失败可能性：什么情况下这个方法可能无效

**⑤ 和其他方法比有什么不同？（对比分析）**

| 对比维度 | 本方法 | 方法A（常见替代方案） | 方法B（另一个替代方案） |
|---------|--------|---------------------|---------------------|
| 核心思想 | | | |
| 适合人群 | | | |
| 投入成本 | | | |
| 见效周期 | | | |
| 最大风险 | | | |

**⑥ 今天就做的一件事（最小行动）**

读者看完后，**现在立刻能做的一个最小行动**：
- 具体动作（如"打开手机备忘录，写下一个你最近拖延的任务"）
- 预计耗时
- 做完后的预期感受

---

🔗 **信息来源：** 书籍（作者，出版年份）/ 研究论文（作者，期刊）/ 课程名称 / 博客文章标题（日期）
```

### 3. 篇幅要求
- **取消行数上限**，每条正文不少于 **20 行**（不含标题/分隔线/来源）
- 第②部分（原理）不少于 300 字，第③部分（实操）不少于 300 字
- **宁可写 5 条透彻的，不要写 12 条敷衍的**
- 每条要有「读一篇技术博客」的知识密度
- ❌ 禁止：简短列举、空洞鼓励、只有步骤没有原理

### 4. 覆盖面要求
- 8-12 条按轮换分配：聚焦方向 6-8 条 + 其余方向合选 2-4 条
- 同一方向最多选 3 条

### 5. 信息来源要求
- 每条末尾标注真实来源
- 方法类优先引用权威来源（书籍/研究/知名博客）

### 6. 禁止行为
- ❌ **鸡汤式内容**（"只要努力就能成功""学会这个方法你就能改变人生"——没有原理支撑）
- ❌ **无时效性关联**（每条必须说"为什么现在值得关注"）
- ❌ **只有步骤没有原理**（只写"第一步做A第二步做B"，不解释为什么有效）
- ❌ **堆砌名词**（只说概念不深入讲解）
- ❌ **简短条目**（正文少于 20 行的速写式内容）
- ❌ **虚构案例和数据**——没有来源的效果承诺

## 🎯 定位与要求

- 🎯 **知识价值第一**：每条要让读者看完后真正**理解**这个方法为什么有效，而不只是知道怎么照着做
- 🎯 **原理驱动**：每条必须讲清楚背后的认知科学/心理学/行为学原理，让读者知其然更知其所以然
- 🎯 **时效性关联**：每条必须说明这个提升方向为什么在当前时间点特别值得关注
- 🎯 **多维度覆盖**：同时覆盖硬技能（编程/写作/表达）和软技能（思维/习惯/沟通/情商）
- 🎯 **低成本**：优先推荐免费/低成本方法，避免需要大额投入的提升方案
- 🎯 **宁可少写几条，也要每条写透**：如果当天搜不到足够有深度的素材，可以降到 5-6 条但每条都写扎实
