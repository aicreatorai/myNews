### 1. 【Cursor AI：Agent 帮你从空目录到可运行应用】

> 📍 **导语**（约 110 字）：写代码最耗时的不是敲键盘，而是把一个模糊需求推进到能跑的项目：定方案、搭脚手架、写功能、过测试、修报错，常在编辑器、终端、文档间反复横跳。Cursor 是 VS Code 同源的 AI 编程编辑器，2026 年它的 Agent、Plan、Ask、Composer 与 .cursor/rules 已能形成一条可复用的开发流水线。今天用十分钟学会这套"先规划再生成"的实战工作流，把原型开发速度拉满。

**🛠 深度实操指南**

**▌ 工具速览**（它是什么）
Cursor 是基于 VS Code 开源内核的 AI 原生代码编辑器，最大优势是"上下文感知"：它会索引整个代码库，在你提问或改代码时自动带入相关文件、类型与测试。相比逐行补全的 Copilot，Cursor 提供四种核心交互：Chat（Cmd+L，理解代码问答）、Inline Edit（Cmd+K，单文件快改）、Composer（Cmd+I，跨多文件重构）、Agent 模式（自主跑命令、建文件、执行测试）。2026 年 8 月版本 v1.2.0 已支持 Auto-Run 自动执行构建、Plan 模式先出方案、Ask 模式只读规划，价格免费版可用、Pro 约 15 美元/月。

**▌ 核心功能场景化拆解**（解决什么）
· 全新项目冷启动：PM 丢一句"做个简化版 Trello，聚焦每日站会"，你用 Ask 模式先把模糊需求逼成可构建的 PRD，再让 Agent 一键生成脚手架（含配置、目录、初始依赖），几小时变可运行原型。
· 既有大库改造：对几万文件的老仓库，Cursor 索引后知道谁调用了谁，重构函数名能跨文件同步，比"贴片段问"稳得多。
· 复杂功能分解：用 Plan 模式先研究代码库、抛出架构权衡（WebSocket 还是 SSE？状态放 URL 还是 local state？），确认后再让 Agent 写，避免一头扎进去返工。
· 调试与测试：报错后让 Agent 读日志、跑测试、自修，闭环到通过。

**▌ 实战工作流**（原理）
一套可复制的新项目流水线分六步。第一步，用 Ask 模式（只读、不改文件）把模糊需求逼成清晰 PRD，模型会反问范围与权衡，像跟资深工程师对谈。第二步，切到 Agent 模式，让 Cursor 把 PRD 写成 docs/prd.md 文件，后续用 @docs/prd.md 引用，防止长对话跑偏。第三步，最关键也最常被跳过：在写任何代码前建 .cursor/rules 目录，用 .mdc 文件写明技术栈、命名规范、目录约定（如"Python 用 snake_case、TS 用 camelCase、测试放 __tests__"），这些规则会自动注入每次对话。第四步，Agent 模式搭脚手架并开 Auto-Run，它自行执行命令、建文件、起 dev server；成功后立即 git 提交做第一个安全还原点。第五步，复杂功能先切 Plan 模式（Shift+Tab）研究代码库并产出可审阅的实现计划，再交给 Agent 写。第六步，用 @文件名 给模型精准上下文，避免它乱拉无关文件。整套逻辑是"规划→规则→脚手架→检查点→分解→精准上下文"，把 AI 从"补代码"升级成"交付项目"。

**▌ 动手验证**
场景：从零做一个带实时看板的小项目。
Step 1：开 Cursor，按 Cmd+. 切 Ask 模式，输入"我要做聚焦每日站会的极简看板，列 To Do/In Progress/Done，支持拖拽与多人实时更新，给我 PRD"。
Step 2：切 Agent 模式，命令"按 PRD 创建 docs/prd.md，并搭建 Next.js + 数据库脚手架"。
Step 3：建 .cursor/rules/backend.mdc，写入技术约定；让 Agent 脚手架并 Auto-Run，成功即 git commit。
Step 4：对"看板拖拽"功能用 Plan 模式先出方案，确认 WebSocket vs SSE 选型后再生成。
Step 5：用 @src/db/schema.ts 给上下文，让 Agent 实现列与卡片模型；跑测试直到通过。关键心得：先规则后代码 + 每步 git 检查点，比裸聊快且不易崩。

**▌ 进阶技巧**（选填）
把常用约定固化进 .cursor/rules 后，所有后续对话自动遵循；用 @引用精准文件而非整库搜索；开启 Auto-Run 让 Agent 自跑构建与测试；长任务用 Plan 模式先对齐架构再动手，能显著降低返工率。团队可把 rules 文件纳入版本库共享。

**▌ 选型对比**
| 维度 | Cursor | GitHub Copilot | Codeium |
|------|------|------|------|
| 适合 | 整项目/Agent | GitHub 生态 | 多语言补全 |
| 上下文 | 全库索引 | 中等 | 中等 |
| 多文件 | Composer强 | 弱 | 一般 |
| 价格 | 免费/15刀 | 10刀 | 免费起 |

### 2. 【ComfyUI：把 AI 绘画变成可复用节点生产线】

> 📍 **导语**（约 115 字）：很多人用文生图工具像"抽卡"——填一堆参数、点生成、看运气。ComfyUI 反其道而行：它用可视化节点把"提示词→模型→采样→解码→出图"整条链路摊开在你面前，每个步骤可见、可调、可保存成 JSON 一键复用。2026 年它的 ControlNet 控图、LoRA 换风格、FaceDetailer 修脸、高清放大与图生视频均已成熟，电商修图、游戏道具、社媒配图都能跑出商业级成品。今天学会搭一条"基础文生图 + 高清修复"的工作流，从此告别随缘出图。

**🛠 深度实操指南**

**▌ 工具速览**（它是什么）
ComfyUI 是一款基于节点式工作流的本地 AI 绘画引擎，底层跑 Stable Diffusion 等开源模型。与传统 WebUI 的"填表单"不同，它把每个处理步骤做成一个节点，用连线表达数据流向，你能像素级控制生成过程。它显存占用低，4GB 也能跑；工作流可存成 JSON 文件一键保存与分享，插件生态极丰富。2026 年官方还推出 App Mode 简化视图，新手先用车模式、熟悉后再翻回节点图深挖。简单说，它是"永不打烊的虚拟摄影棚"，把出图从抽奖变成可控生产线。

**▌ 核心功能场景化拆解**（解决什么）
· 基础文生图：双击空白搜节点，依次连 CLIP 文本编码器（正/反向提示词）→ Checkpoint 加载器 → K 采样器 → VAE 解码 → 保存图像，调采样步数、CFG、种子、分辨率即可出图。
· 精准控图：ControlNet 是灵魂，上传参考图做 OpenPose 锁姿态、Canny 锁轮廓、Depth 锁景深，AI 不再天马行空乱画。
· 风格一键换：LoRA 像滤镜库，几十 MB 就能把画面切到动漫、赛博朋克、汉服，强度 0.3–0.7 可控。
· 后期精修：FaceDetailer 自动修五官、Tile 模型放大增强，传统修图师数小时的活压到秒级。
· 图生视频：接 WanVideo 等节点，让静图"活"过来，做短视频素材。

**▌ 实战工作流**（原理）
一条"高清商业出图"工作流这样搭。第一步部署：镜像一键部署或源码 git clone 后 pip install，浏览器开 127.0.0.1:8188 即可。第二步搭主链路：正/反向提示词独立拆成两个 CLIP 节点，连到 K 采样器，再串 VAE 解码与保存图，确保"模型+提示词→采样去噪→解码→输出"逻辑清晰。第三步嵌高清修复：在出图节点后串联二次采样与 4K 放大节点，采样步数 28–32、降噪强度 0.25，平衡清晰度与原生质感，避免一键极致放大导致油腻失真。第四步加创新模块：风格锁定节点（提取首图特征，批量出图色调统一）、细节补全、商用降噪、智能构图校正，自动修透视与偏移。第五步固化参数并一键封装：把采样步数、降噪、放大倍数写死，新手只输需求就能出图，专业者仍可进节点微调。踩坑提示：节点报错多为模型缺失或插件版本不匹配，统一装最新插件与配套模型即可；低配机可关超高精度节点降负载。

**▌ 动手验证**
场景：做一张赛博朋克武士海报并放大到 4K。
Step 1：双击加节点，连好 CLIP 正/反向、Checkpoint、K 采样器、VAE、保存图。
Step 2：正向提示词写"霓虹街道上的未来主义武士，电影级照明，4K，细节丰富"，反向写"模糊、变形、多余手指"。
Step 3：采样步数 25、CFG 8、固定种子，点 Queue Prompt 出基础图。
Step 4：加 ControlNet（Canny）锁构图，加 LoRA（赛博朋克）强度 0.6；再串高清修复节点，降噪 0.25、步数 30。
Step 5：用 FaceDetailer 修脸、Tile 放大，导出。关键心得：提示词分正负、一次一个主运动、风格锁定保统一。

**▌ 进阶技巧**（选填）
用 ComfyUI Manager 一键装插件是必装第一步；把满意工作流存 JSON，团队间直接分享复用；BizyAir 等 LLM 节点可把一句大白话扩写成专业英文提示词；视频脚本类可接图生视频节点做运动控制。批量出图务必开风格锁定，避免套图色调跑偏。

**▌ 选型对比**
| 维度 | ComfyUI | 传统 WebUI | Midjourney |
|------|------|------|------|
| 可控性 | 像素级 | 有限 | 低 |
| 复用性 | JSON分享 | 难 | 无 |
| 显存 | 低 | 高 | 云端 |
| 门槛 | 中 | 低 | 低 |

### 3. 【Perplexity：带可点击出处的 AI 答案引擎】

> 📍 **导语**（约 115 字）：做竞品分析、行业报告的人常卡在"搜资料 40 分钟、筛网页 30 分钟、核对来源 20 分钟，真正写只剩半小时"。普通搜索给一堆蓝色链接要你自己找，而 AI 概述还截流了自然结果点击。Perplexity 是少有的"带出处"答案引擎：每条回答都附可点击引用，默认实时检索全网，对吃信息饭的运营、投研、内容策划几乎是刚需。2026 年实测把它接入每周竞品情报流程，团队信息整理时间压缩六成。今天学会"结构化提问 + 切源 + 追问 + 抽查出处"的四步法，让每个数据都能回溯原文。

**🛠 深度实操指南**

**▌ 工具速览**（它是什么）
Perplexity 是基于检索增强生成的 AI 答案引擎，架构是"先实时检索、再综合并内联引用"，而非先靠训练记忆再补来源，因此它是当前最透明的 AI 搜索。每月处理超 7.8 亿次查询，每条回答带 5–10 条内联引用，Pro 版还会跑多轮检索产出 8–15 条。它内置学术、财经、社交等多种聚焦源，能反映几天内的新内容，免费版即可跑通基础调研。相较聊天模型，它默认联网、必带引用，对"信息即粮食"的岗位，溯源比文风重要得多。

**▌ 核心功能场景化拆解**（解决什么）
· 竞品情报：问"2026 年 AI 陪伴硬件头部玩家、价格带、用户评价差异，按品牌列"，立刻得带出处对比，省去逐个开网页。
· 行业动态监测：聚焦学术/财经源看报告，切社交源看真实用户反馈，不被娱乐内容淹没。
· 溯源追问：对某个数据追问"出自哪份报告、样本量多少"，它顺着线索继续挖。
· 长链对话：上一轮结论直接变下一轮问题，像和读过全网的研究助理对话。
· 多源切换：按话题切数据源范围，垂直调研更高效。

**▌ 实战工作流**（原理）
Perplexity 的检索优先管线分四步。第一步查询扩展与分类：它解析你的意图（事实/导航/分析/交易），并重写查询以优化召回。第二步实时网页检索：向自有爬虫索引与第三方接口发请求，CEO 公开表示它维护独立爬虫而非仅依赖 Bing/Google，覆盖更独立。第三步来源排序与过滤：按相关性、新鲜度、权威性、多样性打分，并显式避免同域名重复引用，平均每次回答覆盖 5.2 个独立域名。第四步综合并内联引用：语言模型被约束只从过滤后的来源池引用，每条主张链接到编号来源。对专业服务类查询，它还会做三层重排（BM25+向量初检→交叉编码器精排→带实体与权威信号的 ML 重排）。实战中，用 Pro Search 跑多轮检索可得更密引用；问完点开 source 链接抽查一两个关键数据，确认原文语境没被曲解，再把自带结构的答案稍改写进日报。

**▌ 动手验证**
场景：做 AI 硬件竞品定价与功能对比调研。
Step 1：结构化提问"列出 2026 年 AI 陪伴硬件头部品牌、价格带、用户评价差异，按品牌成表"，比搜"AI 硬件"有效得多。
Step 2：切财经/社交源分别看行业报告与真实反馈。
Step 3：对可疑数据追问"这数出自哪份报告、样本量多少"，让它顺线深挖。
Step 4：点开末尾 source 链接，抽查两三个关键数据确认未曲解。
Step 5：复制结构化答案进竞品周报。实测传统方式约 3 小时，用它能压到 40 分钟、且每条有出处。

**▌ 进阶技巧**（选填）
养成"追问来源细节 + 抽查关键数据"的习惯，可信度掌握在自己手里；Pro 版解锁更多专业源与更长追问；垂直行业报告（如非公开券商纪要）它可能搜不到，敏感结论仍以一手信源为准。中文垂直内容覆盖不如本地生态，重要决策交叉验证。

**▌ 选型对比**
| 维度 | Perplexity | ChatGPT | 传统搜索 |
|------|------|------|------|
| 默认联网 | 是 | 否 | 是 |
| 必带引用 | 是 | 否 | 链接 |
| 溯源成本 | 点一下 | 高 | 高 |
| 新鲜度 | 强 | 弱 | 强 |

### 4. 【Gamma：AI 原生演示工具，对话即出 PPT】

> 📍 **导语**（约 110 字）：还在手动拖文本框、对字体、调配色？一份重要汇报常耗掉几小时做版式。Gamma 是 AI 原生的演示工具，你只打一句主题或粘贴文档，它先出大纲、再一键生成含文字、配图、排版的完整 deck，几十秒交付初稿，还能导出 PPT/PDF 或直接在线演示。截至 2026 年它已生成超 2.5 亿份演示、网页与文档，月活用户数千万。对经常做周报、路演、课件的人，它把"设计焦虑"变成"对话式创作"。今天跑通"提示词→大纲确认→生成→精修→导出"的闭环。

**🛠 深度实操指南**

**▌ 工具速览**（它是什么）
Gamma（gamma.app）是 AI 原生的演示、文档与网页生成工具，核心交互是"对话式出稿"。免费版每月约 10 次生成额度，注册即用。它提供 Generate（AI 从零生成）、Paste（整理杂乱笔记）、Import（救活旧 PPT）三种入口；内置数十种主题与品牌模板，自动配智能布局、配色与图标。它不只是做幻灯片，还能生成落地页、文档与社媒图文，所有产物基于网页原生，可嵌入视频、图表与第三方文件。其"Agent"模式能按一句指令重写页面、加时间线，像设计搭档陪你改稿。

**▌ 核心功能场景化拆解**（解决什么）
· 一键 PPT：输入"三年级语文《荷花》课件"或粘贴 Word/PDF，AI 读内容自动拆页，几十秒出含封面、讲解、练习的完整课件。
· 大纲优先：AI 先给大纲，你检查章节顺序与超纲项，确认后再生成，大纲阶段改比生成后改省 10 倍时间。
· 网页/文档：同一套对话还能出产品落地页与长文，跨形态复用内容。
· 实时精修：点任意文字改、点火花图标让 AI 重写、点图换配图、改主题色全局一秒换肤。
· 多格式导出：导出 PPTX（方便二次编辑）、PDF（投屏）、PNG，或生成在线分享链接。

**▌ 实战工作流**（原理）

### 6. 【Kimi：超长上下文把上百页 PDF 读成报告】

> 📍 **导语**（约 110 字）：处理几十上百页的论文、合同、行业报告，最怕两件事：一是复制进普通聊天窗口被截断、丢前文；二是只说"帮我总结"得到空泛套话，不能直接汇报。Kimi 的杀手锏是超长上下文（最高约 200 万 token），能整本读入 PDF、Word、Excel 甚至整个代码库，并保持全文一致性。2026 年 1 月发布的 K2.5 更让 Kimi Agent"驾驭 Office"，端到端输出 Word、PDF、Excel、幻灯片。对长文档总结、多资料对比、合同风险梳理，它是最顺手的分析助理。今天学会"先结构、再重点、后改写"的三轮提问法。

**🛠 深度实操指南**

**▌ 工具速览**（它是什么）
Kimi 是月之暗面（Moonshot AI）推出的长上下文智能助手，核心优势是"读得长、读得全"。它支持上传 PDF、Word、Excel、PPT、图片与代码压缩包，单文件可达约 200 万 token，堪比整本书。交互上有 Chat、K1 增强推理、Search 实时联网三模式；K2.5 后新增 Docs/Sheets/Slides 专属入口，能直接在浏览器生成 .docx/.pdf/.xlsx 并可下载本地续编。免费额度在同类中偏慷慨。它不只能聊，更能当"文档分析助理"：建全文地图、按维度提证据、把零散资料整理成可发布的结构化内容。

**▌ 核心功能场景化拆解**（解决什么）
· 长文档总结：把上百页资料压成核心摘要、章节提纲与结论清单，先结构后重点防遗漏。
· PDF 分析：从政策、行业报告、论文、合同提取关键观点、数据与风险点，要求标页码依据。
· 多资料对比：同时整理多份文档，输出同维度对比表，适合竞品与政策研读。
· 资料库搭建：把零散文件归类成主题、标签、问答库与选题库，支撑持续创作。
· 表格结构化：把文本资料整理为 Excel 可复制的字段、清单与 Markdown 表。

**▌ 实战工作流**（原理）
高效用法是"上传前整理 → 分三轮提问 → 要证据 → 人工校验"。上传前先把文件名改成"主题+时间+类型+版本"，PDF 确认文字可选（扫描件先 OCR），Excel 清理表头，敏感信息脱敏。第一轮看结构：命令"先读全文，输出主题/类型/目录结构/每章要点/最重要 3 章"，建全文地图，显著减少漏章。第二轮抓重点：要 300 字摘要、10 条要点、关键数据与时间机构、不确定项单独列。第三轮按场景改写：如"改写成给管理层的报告，结构含摘要、背景、发现、问题、建议、行动"。提问用"目标+维度+证据"模板，例如合同分析按付款/交付/违约/保密/终止五维度提炼风险并给原文依据；政策文件输出"工作落实清单"表格。全程要求区分"原文内容"与"AI 推断"、标依据位置、列待复核信息，把编造风险压到最低。

**▌ 动手验证**
场景：分析一份 80 页行业报告并产出竞品对比。
