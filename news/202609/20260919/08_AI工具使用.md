### 1. 【Claude Code 项目实战：把需求文档变成可运行代码的 Agent 工作流】

> 📍 **导语**：Claude Code 是 Anthropic 推出的终端 AI 编程代理，能读项目、跑命令、改多文件，但多数人只停留在"会用一点"。本篇用"四件套"派单法和 Plan Mode，把一个模糊需求直接变成可运行、带测试的代码，配合 Git 当安全网，新手也能放心委派复杂任务，看完即可照做。

---

**▌ 它是什么？**

Claude Code 是一个跑在你本地终端的 AI Agent 客户端，和项目目录深度绑定。它能读文件、执行 shell、调用大模型 API，本质像"能力超强但记忆短暂的实习生"——你得给它权限、工位和清楚的任务。它最强的是终端 CLI，也提供 VS Code 插件、桌面端与网页端，多端共享会话。免费层即可起步，Pro 约 20 美元/月、Max 约 100 美元/月解锁更高额度与更强模型，是"干活工具"而非聊天工具。

它解决了什么问题？

传统聊天式 AI 只回答不落地，你还要自己复制代码、手动改文件、挨个跑测试。Claude Code 把"对话"升级成"执行"：它直接在你的仓库里增删改文件、装依赖、跑测试、提 PR，每步都让你审批。它解决三大痛点：一是多文件重构人脑盯不过来；二是新手不知从哪下手；三是复杂任务反复试错成本高。配合 Git 当安全网，把"不敢让 AI 动代码"变成"放心委派"，Anthropic 工程师称其处理了 95% 的 git 操作。对团队而言，把 CLAUDE.md 与 .mcp.json 纳入版本控制，新成员克隆仓库即获得统一项目上下文，比口头交接靠谱得多；企业还可借助 Hook 做确定性自动化，例如保存后自动格式化、拦截对 .env 的修改，全程无需 LLM 参与也能守住工程规范。

核心原理三阶拆解

第一阶 上下文采集：启动即扫描项目结构，结合 CLAUDE.md 项目手册与 .claudeignore 排除项（可省 25%—40% token），建立代码地图，再用 /init 自动生成项目说明。第二阶 Agent Loop：接到任务后循环执行"收集上下文→规划→执行→验证→自我纠正"，直到完成或遇阻；Plan Mode 会先出方案等你批准，避免乱改。第三阶 工具调用与权限：通过 Read/Edit/Write/Bash 落地，危险命令（rm -rf、git push --force）默认拦截需显式放行；MCP 协议再把数据库、GitHub、Slack 外挂进来，让它从"写码助手"升级为"全栈开发代理"。

动手验证

场景：假设你要给一个 Express 项目加邮箱+密码登录，并用 Redis 存会话。
Step 1：在项目根目录运行 claude，先问"What does this project do?"，强迫它先理解代码库再接活。
Step 2：用四件套派单——目标+位置+验证+约束："Add email/password login to this Express app using Passport.js, store sessions in Redis. Don't change session handling in src/utils/auth.ts." 越具体越少返工。
Step 3：按两次 Shift+Tab 进 Plan Mode，审查它提出的方案与要改的文件清单，确认后再放行执行。
Step 4：它创建路由、装依赖、跑测试，每步 diff 你点 Approve；若测试失败，把报错整段粘贴让它修，它常能自己定位。
Step 5：跑通后 git commit 落盘。关键心得：先用 Plan Mode 对齐 3 分钟，省下后面约 30 分钟返工；Context 用到 50% 就 /compact，70% 直接 /clear 重开。进阶技巧：用 git worktree 开并行会话同时做不同功能互不干扰；用 /cost 盯 token 消耗；按任务档位切模型，常规用 Sonnet、复杂决策用 Opus、简单查询用 Haiku，能在质量与成本间取得平衡。

对比与选型

|---------|----------|--------|--------|
| 适合任务 | 多文件代理改动 | 精细控制编辑 | 行内补全 |
| 不适合 | 单纯问答 | 全自动委派 | 复杂重构 |
| 学习成本 | 中 | 低 | 低 |
| 价格 | Pro 20美元/月 | 20美元/月 | 10美元/月 |

### 2. 【Windsurf AI 编程实战：Cascade 代理把多文件改动一次做完】

> 📍 **导语**：Windsurf 是基于 VS Code 的 AI 优先编辑器，内置 Cascade 代理能读整个代码库、跨多文件规划并落地改动，还能自己跑终端验证。它免费版就给无限 Tab 补全与内联编辑，对从 VS Code 迁移的用户几乎零门槛。本篇带你用 Cascade 把"加个功能"变成一次审核即用的交付。

---

**▌ 它是什么？**

Windsurf（前身 Codeium Editor）是由 Codeium 打造、后被 Cognition 收购的 AI 代码编辑器，本质是 VS Code 的一个分支，因此你的快捷键、设置与大部分插件都能一键导入。它内嵌名为 Cascade 的 AI 代理：你用自然语言描述改动，它读相关文件、规划、跨文件编辑，并在执行前展示 diff 供你审批。免费版包含无限 Tab 补全、无限内联编辑与每日代理额度；付费档解锁更高额度与 Claude、GPT、Gemini 等前沿模型。

它解决了什么问题？

手动编码时，加一个跨多文件的功能要在十几个地方来回改，容易漏、易出错。Cascade 把"多个单点编辑"合并成"一次代理任务"：它理解项目结构后统一规划、统一改、统一跑命令验证。它解决三个痛点：一是多文件特性开发心智负担重；二是新手不会组织改动顺序；三是改完不敢确定是否破坏构建。Cascade 的 diff 审批流和"自己跑测试"行为，让"快"和"稳"可以同时拿到，社区称其最强场景正是加功能与修构建。此外，Windsurf 是 VS Code 分支，你的快捷键、设置与大多数插件能一键迁入，切换成本极低；社区建议把重复操作存成 workflows，让代理越用越懂你的代码习惯，后续会话直接复用既定规则与偏好。

核心原理三阶拆解

第一阶 代码库索引：打开项目文件夹后，Windsurf 自动读取代码结构建立索引，上下文感知依赖"完整项目打开"，越完整编辑越贴合你的风格。第二阶 代理规划与编辑：Cascade 收到指令后先列出要建/改的文件与命令，展示计划再执行；Write 模式可建文件、跑终端、装依赖、开浏览器预览，所有改动以可见 diff 呈现。第三阶 验证与记忆：它能在集成终端自行跑测试、读报错并自我修复；会话记忆你定下的规则与偏好，可存为 workflows 复用，配合 .windsurfrules 强制策略，MCP 再打通外部工具。

动手验证

场景：假设你要给 Python 项目加一个"读取 sales.csv 按地区汇总营收"的脚本。
Step 1：打开干净文件夹 weekly-summary，确保项目完整以便索引；个人使用免费版即可。
Step 2：按 Cmd+L（Windows Ctrl+L）打开 Cascade，选 Agent 模式，输入详细任务："Create generate_report.py that reads data/customers.csv with columns customer_id, name, revenue, last_order_date, output an HTML report with top 10 by revenue and accounts inactive 60+ days, use pandas, create a 20-row sample CSV, then run it."
Step 3：审查它给出的计划与要装的包（如 pandas），不明白就让它解释，避免它建到错误目录。
Step 4：放行后看它建文件、pip 安装、执行脚本，终端报错它会自己修并重跑——这是最有价值的行为。
Step 5：浏览器打开 HTML 核对数字与源数据，读一遍代码确认无越权上传，再提交仓库。关键心得：把大需求拆小、逐次派活，比一次"做个完整应用"产出更可控。进阶做法：用 Ctrl+I 做单点内联编辑（免费、不计额度），把 Ctrl+L 的 Cascade 留给真正跨文件、需推理的任务；批量相关改动合并成一条清晰指令，能显著减少额度消耗，因为每次代理任务无论大小都计额度，宁可用少而清晰的指令。

对比与选型

| 决策维度 | Windsurf | Cursor | VS Code插件 |
|---------|----------|--------|----------|
| 适合任务 | 代理式多文件 | 精细控制 | 轻量补全 |
| 不适合 | 单纯问答 | 全自动委派 | 复杂重构 |
| 学习成本 | 低 | 低 | 低 |
| 价格 | 免费起 | 20美元/月 | 多数免费 |

### 3. 【秘塔 AI 搜索使用指南：中文长文与学术溯源的高效检索】

> 📍 **导语**：秘塔 AI 搜索（metaso.cn）是国内最早专注 AI 搜索的产品之一，无广告、直达带引用结果，对中文长句与本土数据源理解更深。它不止给答案，还附大纲、思维导图与可溯源脚注，特别适合写文献综述与行业分析。本篇教你用"学术模式+深入模式"把一句宽泛提问变成可复核的证据链。

---

**▌ 它是什么？**

秘塔 AI 搜索由上海秘塔网络科技提供，官方自称"0.99 版"。它和普通搜索引擎、通用聊天模型、专业数据库都不同：普通引擎只给链接列表，秘塔会归纳组织并生成带信源线索的回答；聊天模型可能凭记忆作答，秘塔更强调联网检索、来源聚合与追问。它提供全网、文库、学术等范围与简洁、深入、深度检索等模式，还支持文件上传、专题资料库与"今天学点啥"，结果默认加密存私有云。

它解决了什么问题？

写论文或做行业研究时，最怕两件事：一是大模型"文献幻觉"编造不存在的引用；二是搜到一堆链接却拼不出可信结论。秘塔把"搜答案"升级为"找证据"：每条结论都带可追溯脚注与原文链接，学术模式直连中英文库、PubMed、北大核心等，从源头抑制幻觉。它解决三痛点：长句口语化中文检索不友好、跨源信息难汇总、引用格式手搓费时。馆员实务指南指出，它适合选题探索、关键词扩展与证据线索整理，但不能替代专业库原文核验。对职场人，它还能把搜索结果一键转成幻灯片、半小时搭好汇报框架；学术模式直连中英文库与引文索引，把读十篇论文压缩成带摘要与引用脉络的速览，写综述效率提升一个量级。

核心原理三阶拆解

第一阶 意图理解与多源聚合：自研 MetaLLM 深度理解问题，跨中英文网站、公众号、学术库检索聚合，输出带引用标注的结构化答案。第二阶 规划式检索：深度检索采用"先想后搜"：先建研究框架与维度，再分路搜索、多线迭代，直至逻辑闭环，合并成带证据链的报告。第三阶 溯源与呈现：每句结论附脚注可跳转原源，结果下方自动生成大纲、思维导图与对比表，可一键导出；学术模式对接引文索引，支持摘要速览与规范引用生成。

动手验证

场景：假设你要写"2026 年中国 AI 编程工具市场格局"的文献综述框架。
Step 1：打开 metaso.cn，搜索框左下角把来源切到"学术"，细分选"中英文库"或"中科院分区"，模型选"长思考"即可。
Step 2：输入结构化问题而非关键词："总结 2026 年国内 AI 编程工具的主要玩家、技术路线与商业模式，列出可引用的中英文文献。" 用"深入模式"兼顾效率与质量。
Step 3：查看返回的大纲与脚注，点击数字跳转原文核验；对关键数据点用"事实核验"功能交叉比对，识别同源转载。
Step 4：切到"今天学点啥"，把导出的综述框架文档丢进去，划定页码让 AI 逐段精讲，把读文献变成上课。
Step 5：把可信来源转入知网/万方继续核验，输出"主张—来源—原文位置—核验状态"记录。对关键政策类问题，用"事实核验"交叉比对，识别范围偷换与同源转载风险后再采信。关键心得：AI 生成回答不是证据，原始来源与支持关系才是。

### 4. 【Genspark AI 搜索实战：多引擎聚合与超级 Agent 生成可溯源报告】

> 📍 **导语**：Genspark 不是普通搜索引擎，而是 Agent 式研究平台：你描述任务，多个专业智能体并行检索网页、论文、官方源，再缝合出带内联引用的 Sparkpage 报告。免费版每日给额度，标准对话零消耗。本篇用"清晰研究简报式提示词"在十分钟内拿到可交付调研，适合会议前快速补课。

---

**▌ 它是什么？**

Genspark（genspark.ai）由前百度小度 CEO 创立，采用"多智能体混合"架构，集成多个差异化大模型与数十种工具。它两大核心产出：一是 Sparkpage——把"需读十个网页才拼出的答案"直接做成一页结构化、带引用、可分享的报告；二是 AI Super Agent——能自主跑多步任务，如搜公司、比价、总结优劣，甚至代你打真实电话核实信息。免费版可用基础搜索与 Sparkpage，每日给额度；Plus 档解除上限并解锁更强代理模式，标准聊天与图像生成长期零消耗。

它解决了什么问题？

传统"开 30 个标签页、扫维基、碰运气"的研究方式慢且易漏。Genspark 把研究委派给并行智能体：一个搜开放网页、一个读论文、一个拉官方源、一个看新闻，再由合成智能体拼成带引用的简报，平均 8—11 分钟完成人类两三小时的活。它解决三痛点：跨源信息难汇总、关键数据无出处、复杂任务要人盯全程。其对关键点要求至少三方信源交叉验证，官方称虚假信息过滤率很高，让"派活"比"搜索"更省心。对个人用户，免费档即可应付日常调研与课程作业，不必为偶尔的研究需求订阅昂贵工具，是轻量上手的研究入口。

核心原理三阶拆解

第一阶 多智能体分工：每个查询不是单模型作答，而是内容生成、事实核查、溯源仲裁等角色协同；某句结论在权威源找不到依据会被自动降权、标灰。第二阶 规划式深度调研：复杂问题被拆成若干子任务（如财务、产业、专利、机构持仓），分别派给对应智能体并行处理，再整合为带图表与参考文献的报告。第三阶 异步与验证：Autopilot 代理可后台运行数小时，自动刷新数据、抓新论文、重算模型，完成后才推送；用户可点"深度校验链"强制调多个权威源比对，结果可存文件夹复用。

动手验证

场景：假设一小时后要跟老板聊"是否 2026 年进入新加坡电动车市场"，你需要两份简报。
Step 1：用邮箱或 Google 注册免费账号，进主工作区，模式选择器挑"Deep Research（深度调研）"而非标准搜索。
Step 2：写分析师式提示词，含受众、决策与结构："I need a 2-page brief on Singapore EV market for senior leadership deciding 2026 entry. Cover market size, top 5 makers by share, 2025—2027 incentives, charging gaps, adoption barriers, 3 recommendations. Cite all sources inline."
Step 3：点搜索，让代理并行工作 8—12 分钟；期间可离开，完成后看 Sparkpage 的摘要、对比表与来源。
Step 4：用追问精炼："Add a pricing section for each tool" 或 "What's the source for claim X?" 让引用更扎实。
Step 5：导出 PDF/PPT 直接汇报，或存文件夹团队共享。关键心得：提示词写清受众与决策，质量差一个量级。

### 5. 【Suno AI 音乐生成上手教程：从一句描述到完整编曲】

> 📍 **导语**：Suno 让你用文字直接生成带人声的完整歌曲，约一分钟出两版，免费版每日给额度足够练手。它不要求乐理，关键是把"一句感觉"写成含风格、情绪、乐器、人声、速度的六要素提示词。本篇从 Simple 到 Custom，带你做出可下载、能用的配乐或完整曲。

---

**▌ 它是什么？**

Suno（suno.com）是文生音乐工具，把一段文字描述或你自己的歌词，变成带演唱的完整曲目。它提供两种模式：Simple 模式只填主题，AI 自动写词写曲，适合快速发想；Custom 模式分"歌词"与"风格"两栏，你可手写带 [Verse]/[Chorus] 结构标签的歌词，并精确控制曲风。免费版每日给额度、无需信用卡，每次生成消耗额度并出两版变体；WAV 与分轨需付费档。注册建议用 Outlook 或 Gmail，避免部分邮箱收不到验证码。

它解决了什么问题？

想给视频配乐或写首歌，传统方式要么学 DAW、要么请人，门槛与成本都高。Suno 把"写歌"降维成"写提示词"：你描述风格情绪，它出可听成品。它解决三痛点：无乐理也能出曲、找配乐耗时、人声录制麻烦。但"出一首歌"容易、"出你想要的歌"需技巧——模糊的"伤感好听的歌"几乎必翻车。社区共识是：生产力在于"选择两版里更好的"，而非赌一次就中；商用需对应付费档授权。对自媒体与短视频创作者，Suno 让配乐从"找版权曲"变成"写提示词"，几分钟拿到专属背景乐；对独立音乐人，它是低成本 Demo 工具，先用 AI 出结构参考，再进 DAW 用自己音色重制，兼顾灵感触发与版权清晰，是传统制作流程之外的高性价比补充。

核心原理三阶拆解

第一阶 文本到音乐映射：风格栏用"曲风+情绪+乐器+BPM+约束"描述，越具体模型越稳；人声栏用 [Instrumental] 或分段标签控制结构。第二阶 双版生成与试听：每次生成两版变体，你需完整听前三秒、中频是否压人声、有无刺耳峰，再选 hook 更清晰的保留。第三阶 延展与导出：单条时长有限，好开头用 Extend 从时间戳续写，串 3—5 段拼成 3—4 分钟完整曲；下载 MP3 进 DAW 可仅作结构参考重制，付费档还能下分轨精细混音。

动手验证

场景：假设你要给一条旅行 vlog 做无人声背景乐。
Step 1：登录 Suno，开 Custom 模式；Lyrics 栏写 [Instrumental] 或留空并加 "instrumental, no vocals"，避免人声压旁白。
Step 2：Style 栏写六要素："travel vlog bed, instrumental, no vocals, soft acoustic, warm pads, 92 BPM, spacious, VO-friendly"，英文风格词通常更稳。
Step 3：点 Create，约 10—30 秒出两版；完整试听，挑中频留给语音、无突兀掉落的那版。
Step 4：若副歌好但结尾空，用 Extend 从合适时间戳续写"add a bridge then final chorus"，每次续写耗额度，别整首重生成。

**▌ 它是什么？**

它解决了什么问题？
