**▌ 核心原理与架构**（200-350字）
Siteimprove.ai-MCP-Server基于MCP（Model Context Protocol）协议，将Siteimprove的专业无障碍性检测引擎封装为标准的MCP服务器：

```
输入: 网页URL/HTML片段/设计文件/代码片段
  ↓
[解析层]：根据输入类型选择解析器
  - HTML解析器：提取DOM结构和语义信息
  - 设计文件解析器：解析Figma/Sketch/Adobe XD文件
  - 代码解析器：分析React/Vue/Angular组件
  ↓
[检测引擎层]：Siteimprove核心检测引擎
  - WCAG规则库：2000+条检测规则，实时更新
  - 机器学习模型：识别复杂模式（如逻辑焦点顺序）
  - 启发式算法：推断可能的问题
  ↓
[结果格式化层]：转换为MCP标准格式
  - 严重性分级：Critical/High/Medium/Low
  - 修复建议：具体的代码修改建议
  - 合规标准：引用具体的WCAG条款
  ↓
输出: 结构化检测结果（通过MCP协议返回）
```

**关键设计决策**：
1. **多输入源支持**：不仅支持URL，还支持代码片段、设计文件，覆盖开发全流程
2. **增量检测**：对大型应用支持增量扫描，只检测变更部分
3. **规则优先级**：基于实际影响对规则进行优先级排序，开发者先解决最重要的问题
4. **离线模式**：支持完全离线运行，保护代码隐私

**使用本项目的推荐方案**：
```python
# 基于项目的推荐框架组合：CrewAI（协作）+ LangChain（工具链）
from crewai import Agent, Task, Crew, Process
from langchain.tools import DuckDuckGoSearchRun, WikipediaQueryRun

# 1. 定义5个专业Agent
topic_agent = Agent(
    role='选题专家',
    goal='分析热点趋势，提出有价值的新闻选题',
    tools=[DuckDuckGoSearchRun(), trend_analysis_tool],
    verbose=True
)

research_agent = Agent(
    role='调研记者',
    goal='收集选题相关资料，整理事实和数据',
    tools=[WikipediaQueryRun(), web_scraper_tool],
    verbose=True
)

writing_agent = Agent(
    role='资深编辑',
    goal='根据选题和素材撰写高质量新闻稿',
    tools=[grammar_check_tool, style_guide_tool],
    verbose=True
)

review_agent = Agent(
    role='内容审核',
    goal='检查文章质量，确保事实准确、无偏见',
    tools=[fact_check_tool, bias_detection_tool],
    verbose=True
)

publish_agent = Agent(
    role='发布经理',
    goal='将文章格式化为不同平台要求',
    tools=[wechat_formatter, toutiao_formatter, weibo_formatter],
    verbose=True
)

# 2. 定义任务链
topic_task = Task(
    description='分析今日热点，提出3个新闻选题',
    agent=topic_agent,
    expected_output='3个选题标题和简要说明'
)

research_task = Task(
    description='为{选题}收集相关资料',
    agent=research_agent,
    context=[topic_task],
    expected_output='整理好的事实、数据、引用来源'
)

# ... 其他任务定义

# 3. 创建Crew并执行
news_crew = Crew(
    agents=[topic_agent, research_agent, writing_agent, review_agent, publish_agent],
    tasks=[topic_task, research_task, writing_task, review_task, publish_task],
    process=Process.sequential  # 顺序执行，也可并行
)

result = news_crew.kickoff(inputs={'date': '2026-07-07'})
print(result)
```
