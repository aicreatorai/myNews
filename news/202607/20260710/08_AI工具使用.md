### 1. 【Claude Code子代理+钩子：把重复开发交给AI自动跑】

> 📍 **导语**（110字）：Claude Code 是 Anthropic 推出的终端AI编程代理。2026年它的"子代理（sub-agent）+ 钩子（hook）"机制让开发者把检索、测试、修复等重复工程任务拆给专职Agent并行处理，主Agent只做编排。本文带你跑通一套可复用的自动化开发流。

---

**🛠 深度实操指南**

**▌ 工具速览**（120字）
Claude Code 运行在终端，能读写代码库、执行命令、调用工具。它支持把大任务拆给多个子代理（检索Agent、测试Agent、修复Agent）并行；钩子（hook）能在 git commit、文件写入等事件自动触发检查（跑 lint、生成文档）。免费层有限额，Pro/Team 版适合团队日常使用。它是当前AI coding 标杆，核心价值在"自主执行"而非"补全"。

**▌ 核心功能场景化拆解**（180字）
- **子代理并行**：让"检索Agent"找相关代码、"测试Agent"补用例、"修复Agent"改bug，主Agent只汇总，速度远快于串行。
- **钩子自动化**：配置 `PostToolUse` 钩子在每次写文件后自动跑格式化与单测，防止坏代码入库。
- **权限分层**：危险命令需人工确认，普通读操作自动放行。80%的人只用腻了补全，没用上编排能力。

**▌ 实战工作流**（300字）
场景：你接到"给用户模块加手机号校验"的需求。
```
Step 1: 启动并授权
  $ claude  → 进入项目目录，允许它读代码库
Step 2: 派发子代理检索
  "先用检索Agent找出所有处理用户注册的代码与校验函数"
  （主Agent等待，检索Agent返回文件清单）
Step 3: 主Agent实现
  "在 register 接口加入手机号正则校验，并写一条单测"
  → Claude Code 修改 service/user.go，生成 user_test.go
Step 4: 钩子自动检查
  PostToolUse 钩子触发 → gofmt + go test ./... 自动跑
  → 测试失败时，修复Agent介入修正
Step 5: 提交
  /commit 让AI按改动生成规范commit message
关键心得：同等需求，编排式比"一行行让它写"快约2倍，且测试覆盖率更高。
```

**▌ 进阶技巧**（100字）
把优质提示词沉淀成 `CLAUDE.md` 项目记忆文件，团队共享编码规范；用 `settings.json` 配置允许/禁止的命令清单，把钩子接入 CI，让AI改动也过门禁。

**▌ 选型对比**
| 决策维度 | Claude Code | Cursor | Copilot |
|---------|-----------|--------|---------|
| 自主执行 | 强 | 中 | 弱 |
| 终端集成 | 原生 | IDE内 | IDE内 |
| 子代理 | 支持 | 弱 | 无 |
| 适合 | 工程自动化 | 日常补全 | 轻量补全 |

### 2. 【秘塔AI搜索"深度研究"：免费搞定一份调研报告】

> 📍 **导语**（110字）：秘塔AI搜索是国内首个免费公开的"深度研究（Deep Research）"工具，对标 Perplexity 与海外 Deep Research。它能在数分钟内产出带引用、可溯源的结构化调研报告，覆盖全网/学术/文库。本文实测它怎么用、比传统搜索强在哪。

---

**🛠 深度实操指南**

**▌ 工具速览**（120字）
秘塔AI搜索（metaso.cn）主打"无广告、直达结果"，支持上传文件、自定义技能。其"深度研究"模式登录即可用，无需申请或付费。搜索范围细分"全网/文库/学术/图片/视频/播客/我的"，公域私域通吃。对研究者、学生、职场人都零门槛，2025年7月免费开放后被称为"国产Deep Research黑马"。

**▌ 核心功能场景化拆解**（180字）
- **结构化答案**：不是丢一堆链接，而是直接给"来龙去脉"式的报告，并标注信息来源。
- **多范围检索**：写论文选"学术"、做竞品选"全网"、查内部资料选"我的"（可上传PDF）。
- **过程可见**：完整思考链可追溯，方便核对与二次追问。相比传统搜索，省去自己拼凑信息的时间。

**▌ 实战工作流**（300字）
场景：老板让你"一周内摸清AI教育赛道竞争格局"。
```
Step 1: 打开 metaso.cn，切到"深度研究"
Step 2: 输入问题
  "2026年中国AI教育赛道主要玩家、融资与产品形态，
   对比学而思、科大讯飞、豆包，输出结构化报告"
Step 3: 等待 2-5 分钟 → 生成带章节的报告
  （含市场格局、代表产品、数据来源链接）
Step 4: 判断质量
  看"信息来源"是否权威（教育部/公司财报/媒体报道）
  关键数据是否带出处，避免被一本正经地编造
Step 5: 追问迭代
  "把学而思和科大讯飞按营收、用户数做对比表"
  → 在报告基础上细化，导出用于汇报
关键心得：过去人工调研要1-2天，秘塔30分钟出初稿，人只做核实与润色。
```

**▌ 进阶技巧**（100字）
用"我的"上传内部资料做私有化研究；对比同一问题在秘塔与Perplexity的结果交叉验证；长报告用"文库"范围锁定论文源，减少营销内容干扰。

**▌ 选型对比**
| 决策维度 | 秘塔(深度研究) | Perplexity | 传统搜索 |
|---------|--------------|-----------|---------|
| 中文资源 | 强 | 中 | 强 |
| 免费深度研究 | 有 | 限 | 无 |
| 溯源 | 强 | 强 | 弱(需自找) |
| 适合 | 中文调研 | 英文调研 | 快速找链接 |

🔗 **信息来源：** 秘塔AI搜索官网（metaso.cn）/ 量子位《国产Deep Research黑马》（2025-07）/ 知乎《2026 AI搜索实测》（2026-04）

### 3. 【用n8n搭一条AI自动化流水线：从抓取到发布】

> 📍 **导语**（110字）：n8n 是2026年最火的开源工作流自动化工具，被称"瑞士军刀"——拖拽节点即可把"数据抓取→AI处理→发布"串成24小时自动跑的流水线，还能接MCP做智能体。本文用"每日资讯自动汇总发群"为例，带你从零搭一条。

---

**🛠 深度实操指南**

**▌ 工具速览**（120字）
n8n 是公平代码（fair-code）许可的开源自动化平台，支持私有化部署（Docker一键起），内置300+应用节点与AI Agent节点，可连数据库、Webhook、各类SaaS。2026年6月腾讯云评测称其与Dify并称"AI落地开源三剑客"。优势：数据自持、可编码可拖拽、成本远低于SaaS自动化。

**▌ 核心功能场景化拆解**（180字）
- **节点编排**：每个动作是一个节点，连线即流程，可视化但支持写JS/Python表达式。
- **AI Agent节点**：内置Chat模型、记忆、工具调用，能接DeepSeek/MCP。
- **触发方式**：定时（cron）、Webhook、表单、邮件等，适合"无人值守"场景。

**▌ 实战工作流**（300字）
场景：每天8点自动汇总科技新闻，生成摘要发到飞书群。
```
Step 1: 部署
  docker run -p 5678:5678 n8nio/n8n   → 浏览器打开 localhost:5678
Step 2: 定时触发
  加 Schedule 节点：Cron 每天 08:00
Step 3: 抓取
  HTTP Request 节点拉取 RSS/API（如几个科技媒体源）
Step 4: AI 处理
  AI Agent 节点：把抓取文本 → "提炼3条要点+一句话点评"
Step 5: 发送
  Feishu/Lark 节点把结果 POST 到群机器人 Webhook
Step 6: 运行验证
  点"Execute Workflow"手动跑一次，看输出格式再调 Prompt
关键心得：零代码搭出这条线约30分钟；之后每天自动跑，省下人工剪报。
```

**▌ 进阶技巧**（100字）
把常用流程存为模板复用；用"环境变量"保管API Key；接MCP Server让Agent能查实时数据；生产环境加错误捕获节点，失败自动告警。

**▌ 选型对比**
| 决策维度 | n8n | Dify | Zapier |
|---------|-----|------|--------|
| 开源私有化 | 是 | 是 | 否 |
| 代码灵活性 | 高 | 中 | 低 |
| AI Agent | 支持 | 强 | 弱 |
| 适合 | 技术团队自动化 | AI应用搭建 | 小白SaaS集成 |

### 4. 【AI效率套件组合：笔记+会议+任务自动化】

> 📍 **导语**（110字）：2026年实测的15款AI效率工具显示，普通人无需编程即可把效率提升数倍——关键是组合使用：AI笔记做知识沉淀、会议助手出纪要、任务自动化串起提醒。本文给一套可立即上手的个人效率工作流。

---

**🛠 深度实操指南**

**▌ 工具速览**（120字）
- **AI笔记**（如Notion AI / 讯飞听见）：语音或文档自动结构化，生成脑图与待办。
- **会议助手**（如飞书妙记 / Otter）：实时转写并产出纪要、待办项。
- **任务自动化**（如Todoist AI / 微信提醒Bot）：自然语言建任务、到期提醒。
三者组合覆盖"信息进入→加工→行动"全链路，且多数支持中文、可本地/私有化。

**▌ 核心功能场景化拆解**（180字）
- **笔记自动化**：开会录音→AI转写→自动提取"决策/待办/风险"三栏。
- **会议闭环**：纪要直接生成飞书任务卡，指派给参会人，到期推送。
- **跨工具联动**：用n8n或Zapier把"新邮件含'周报'→建任务→周五提醒"串成流水线。

**▌ 实战工作流**（300字）
场景：你每周要开3个会、写2份周报，常漏待办。
```
Step 1: 会议中开转写
  飞书妙记实时记录 → 会末自动生成纪要+待办清单
Step 2: 一键转任务
  纪要里的待办 → 点"转为任务" → 进 Todoist/飞书任务，带负责人与DDL
Step 3: 周报自动草稿
  周末用 Notion AI："汇总本周任务完成情况，生成周报"
  → 输出初稿，你只改措辞
Step 4: 防漏提醒
  在自动化工具设"任务到期前1天推送"，避免遗忘
关键心得：这套组合让"信息→行动"不再靠人肉搬运，周报时间从2小时降到20分钟。
```

**▌ 进阶技巧**（100字）
把笔记库按PARA法（项目/领域/资源/归档）分类，AI检索更准；敏感会议选本地转写工具防数据出域；用MCP把笔记库接进Claude Code，让AI基于你的知识库作答。

**▌ 选型对比**
| 决策维度 | Notion AI | 飞书妙记 | 讯飞听见 |
|---------|-----------|---------|---------|
| 笔记结构化 | 强 | 中 | 中 |
| 会议转写 | 中 | 强 | 强 |
| 私有化 | 弱 | 中(企微) | 可本地 |
| 适合 | 知识管理 | 团队协作 | 高精度转写 |
