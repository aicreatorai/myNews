# 11_移动开发（2026-07-13）

> 聚焦 iOS / HarmonyOS / Android / 跨平台 / 移动端 AI 开发新动态。本期覆盖 iOS 27 SDK 迁移硬性要求、Trust Insights 端侧防诈框架、Android 17 Compose 优先、Compose Grid API、Android AppFunctions(MCP)、Android XR 及 iOS 托管资产包等 7/11-7/13 新动向。

---

### 1. 【iOS 27】Xcode 27 SDK强制三项要求：UIScene生命周期与Liquid Glass迁移

iOS 27 SDK(Xcode 27)开始强制执行三项会影响现有 App 的 SDK 级要求。其一，使用新 SDK 构建的 App 必须迁移到基于 Scene 的生命周期，补齐 `UIApplicationSceneManifest` 与 `SceneDelegate`，否则可能启动即崩；其二，App Store Connect 会校验 Info.plist 是否声明启动屏配置，缺失将触发 ITMS-90870 被拒；其三，`UIDesignRequiresCompatibility` 兼容开关在 iOS 27 失效，导航栏、Tab Bar 与自定义 UIKit 样式需重新验证。

🔗 来源：老司机 iOS 周报 #374（2026-07-06）/ Apple 开发者文档

### 2. 【iOS 27】Trust Insights框架落地：设备端实时识别电信诈骗

苹果在 iOS 27 中推出 Trust Insights 开发框架，可在语音通话、短信与电子邮件场景中实时识别社交工程诈骗。该框架完全在设备端运行，仅分析交互模式与上下文，不读取照片、信息或邮件的具体内容，从隐私层面规避了云端上报的合规风险。

🔗 来源：IT之家 / iOS 动态（2026-07-03）

### 3. 【Android 17】进入Compose优先时代：传统View组件转入维护模式

Android 17 将"Compose 优先"写入平台规则：所有新增 API、库、工具与指南均专为 Jetpack Compose 构建。传统的 `android.widget` View 组件及基于 View 的 Jetpack 库(Fragments、RecyclerView)进入维护模式，仅接收关键错误修复、不再新增功能。为降低迁移成本，Android 17 同步推出由 AI 驱动的 Compose 自适应技能，支持 XML 到 Compose 的自动迁移与多窗格布局转换。

🔗 来源：腾讯新闻 / Android Developers（2026-06-19）

### 4. 【Jetpack Compose】Grid API正式落地：原生2D布局原语对标CSS Grid

Compose BOM 2026.04(核心 v1.11)引入真正的 Grid API，作为自适应 2D 布局原语，支持用轨道、间隙与单元格定义布局，尺寸单位涵盖 Dp、百分比、固有内容大小与 CSS 同款的 Fr 分数单位。同一 Grid 可根据设备状态重新配置轨道与跨度，天然适配手机、平板与桌面折叠形态；同版本还带来共享元素调试工具与默认启用的 v2 测试 API（测试调度器改为 StandardTestDispatcher）。

🔗 来源：Google I/O 2026 Android 开发者博客 / alexhilton 技术博客

### 5. 【Android MCP】AppFunctions开放预览：应用变身设备端MCP服务器

Google I/O 2026 展示的 AppFunctions(Android MCP)已开放实验性预览，作为新的平台 API 与 Jetpack 库，允许应用充当设备端模型上下文协议(MCP)服务器，将自身的工具、服务与数据无缝共享给系统与智能体。配合新 skill 可自动在代码库中生成 AppFunctions，并可通过"测试智能体"在模拟智能体环境中调试；目前已有抢先体验计划面向生产部署。

🔗 来源：Android Developers 中文博客（Google I/O '26 专题）

### 6. 【Android XR】Developer Preview 4发布：空间计算开发基础逼近Beta

Android XR Developer Preview 4 已发布，核心库即将进入 Beta：XR Runtime、Jetpack SceneCore 与 ARCore for Jetpack XR 均标注"即将 Beta"。值得关注的是 ARCore 的 Geospatial API，可将数字内容高精度锚定到真实世界坐标，成为位置相关 AR 体验的基石；三星 Galaxy XR 头显已出货，配合 Catalyst 计划的 XREAL Project Aura 等硬件套件，XR "是否来真"的信号已基本明确。

🔗 来源：掘金《Google I/O 2026：Android 开发者需要知道的一切》

### 7. 【iOS 27】Apple托管资产包上线：本地化资源分包缩减安装体积

Apple 在 App Store Connect 中上线 Apple-hosted asset packs，开发者最多可为单个 App 创建 200 个托管资产包，并可按本地化维度拆分资源，使用户仅下载与其设备设置匹配的语言资源，显著缩减安装体积。此外，非本地化资产包已支持在 Linux 上通过 Managed Background Assets Developer Tools 创建与测试。

🔗 来源：Apple TestFlight Release Notes（2026-07-07）
