### 2. 【📄 本周好论文 | OpenDeepThink: Parallel Reasoning via Bradley-Terry】

> 🏷 arXiv 2605.15177 / 2026-05-15 / AI 推理方向研究者

**为什么值得读**

大模型推理存在一个核心瓶颈：单轨迹推理容易"钻牛角尖"，而 OpenDeepThink 提出了一种基于群体智慧的并行推理框架。核心思想是让模型同时生成多条推理路径，再通过 Bradley-Terry 比较机制选出最优解。这种方法在不增加模型规模的前提下，显著提升了推理质量，为"推理即服务"场景提供了新范式——下一阶段的能力提升可能不只来自更大的模型，也来自更聪明的调度策略。

**核心发现**
- 基于 Bradley-Terry 聚合的群体推理，比单轨迹深度思考更稳健
- 在数学推理和代码生成基准上均表现优异
- 提供了一个可演化、可比较、可筛选的推理组织框架

🔗 来源：[arXiv 2605.15177](https://arxiv.org/abs/2605.15177) | [知乎深度解读](https://zhuanlan.zhihu.com/p/2039425194549310961)

### 3. 【🛠 本周好工具 | CodeGraph — 代码知识图谱，让 AI 编码少花钱】

> 🏷 colbymchenry / 免费 / TypeScript / Claude Code / Cursor / Codex

**为什么推荐**

AI 编码代理在探索代码库时，需要反复调用 grep、glob 和 Read 扫描文件，每次工具调用都消耗大量 Token。CodeGraph 为 Claude Code、Cursor、Codex 等工具提供预索引的代码知识图谱——符号关系、调用图、代码结构一目了然，Agent 可以直接查询图谱而非扫描文件。本月新增 20,676 Stars，100% 本地运行，不上传任何代码到云端。对于大型代码库的 AI 辅助开发，这个工具可以显著降低 Token 消耗和响应延迟。

**核心亮点**
- 预索引符号关系和调用图，查询毫秒级响应
- 100% 本地运行，零隐私泄露风险
- 兼容 Claude Code、Cursor、OpenCode、Hermes Agent 等主流工具

🔗 来源：[GitHub - colbymchenry/codegraph](https://github.com/colbymchenry/codegraph)
