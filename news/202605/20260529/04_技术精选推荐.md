### 2. 【📄 本周好论文 | OpenDeepThink: Parallel Reasoning via Bradley-Terry Aggregation】

> 🏷 Shang Zhou等 / arXiv 2605.15177 / 适合：LLM推理优化研究者与工程师

**为什么值得读**

这篇论文提出了一个新颖思路：不再让模型"一个人使劲想"，而是让多个候选解"群体竞争"。传统推理scaling主要扩展深度（延长思维链），OpenDeepThink选择扩展广度——并行采样多个候选解，再用Bradley-Terry模型进行成对比较选最优。在Codeforces上实现Elo +405分的提升。

**核心发现**
- 首个基于种群的test-time compute框架，通过成对比较而非逐点评判选择最优解
- 比较过程中产生的自然语言critique直接用于改进候选解，形成"比较→改进→再比较"的迭代
- 客观可验证领域（数学、编程）收益显著，主观领域效果反而下降
- 框架跨模型可迁移，无需针对特定模型重新调参
- 附带CF-73基准数据集，含73道Codeforces题及国际特级大师标注

🔗 来源：arXiv（https://arxiv.org/abs/2605.15177）| 技术栈解读（https://jishuzhan.net/article/2056001104274100225）

- Agent开发从"定制化"走向"标准化"，开发门槛将大幅降低

### 5. 【🌟 本周好项目 | Agent Skills】

> 🏷 Google Addy Osmani / 开源免费 / GitHub 19k+ stars

**为什么推荐**

这是Google Chrome团队负责人Addy Osmani开源的AI编程Agent技能包，核心思路是：把高级工程师的工作流、质量门禁和最佳实践编码成结构化的Skill文件。目前包含20个Skill、7个Slash命令和3个Agent人设，覆盖代码审查、性能优化、安全审计、测试等软件开发生命周期的关键环节。兼容Claude Code、Cursor、Windsurf等主流AI编程工具。

**核心亮点**
- 20个生产级Skill覆盖从代码审查到性能优化的完整工程流程
- 3个Agent人设（Senior Engineer、Security Expert、Performance Specialist）可按需切换
- 解决了不同AI编程平台技能不互通的痛点，一套技能多平台通用
- 每个Skill都有详细的质量门禁标准，不是简单提示词而是完整工作流
- 社区活跃，持续新增技能，PR贡献文档清晰
