### 1. 【Claude Code 六步工作流：从新手到高手的实战指南】

> 📍 **导语**：Anthropic 推出的 Claude Code 在 2026 年已成为开发者最热议的 AI 编程助手之一。但很多人的使用方式还停留在"在终端里问问题"的初级阶段。真正的高手用的是"规划-执行-记忆"闭环工作流。本文基于 Anthropic 官方工程团队技术文档与多位资深用户的实战经验，系统梳理 Claude Code 的配置技巧、核心命令、六步高效工作流与进阶心法，让你从"能用"进阶到"用好"。

---

**🛠 深度实操指南**

**▌ 工具速览**

Claude Code 是 Anthropic 推出的终端原生 AI 编程助手，不同于 Cursor 这样的 IDE 插件，它直接运行在命令行中，能深度参与从项目初始化、代码编写、测试调试到 Git 操作的完整开发流程。2026 年 4 月 Claude Code 已支持多模型切换（默认搭载 Qwen3-Max，可切换至 Sonnet/Opus/Haiku），并引入自动记忆、Plan Mode 等关键能力。收费方面：通过 Anthropic API 按 Token 计费，或通过 Claude Pro/Max 订阅使用。其最核心的差异化优势是——它不是一个"聊天框"，而是一个能真正理解项目上下文、自主执行任务的 Agent。

**▌ 核心功能场景化拆解**

场景一：**新项目接手——从零理解代码库**。传统方式下，接手一个新项目需要阅读 README、翻阅目录结构、追踪核心逻辑，至少花半天。Claude Code 的 `/init` 命令会自动扫描整个项目，分析目录结构、技术栈、依赖关系和核心模块，生成 `CLAUDE.md` 项目知识文件。跑完 `/init` 后，你对项目的理解就有了一个高质量的起点。

场景二：**需求开发——从规划到执行"一条龙"**。这是 Claude Code 最令人 WOW 的能力。它提供三种工作模式：Default（逐项确认，适合谨慎场景）、Auto-Accept（自动执行文件编辑，适合批量修改）、Plan Mode（只读分析，不做修改）。Plan Mode 是 Claude Code 独有的设计——你可以在不触发任何修改的前提下，让 AI 阅读代码、输出分析方案和实现计划。确认方案后再切换模式执行，完美解决了"AI 改了一堆结果不是我要的"的痛点。

场景三：**经验沉淀——让 AI 越用越懂你**。Claude Code 的三层记忆机制是其他 AI 编程工具不具备的。项目级记忆（`./CLAUDE.md`）存放项目规则和技术约定；用户级记忆（`~/.claude/CLAUDE.md`）存放个人编码习惯和偏好；自动记忆由 AI 自主判断关键信息并写入。这意味着你用得越多，它就越了解你的编码风格。

**▌ 实战工作流**

```
场景：假设你要为一个现有的 Django 项目新增一个"用户消息通知"功能模块

Step 1 - 初始化项目认知
运行 claude /path/to/project 进入项目目录。
输入 /init → AI 自动扫描整个项目，分析 models.py、urls.py、views.py 结构
生成 CLAUDE.md 后，输入 /memory 手动补充："本项目的通知系统需支持站内信和邮件两种方式，ORM 统一使用 Django ORM"

Step 2 - 理解现有代码结构（Plan Mode）
按 Shift+Tab 切换到 Plan Mode（只读模式）
提问："分析现有的 models.py，告诉我 Message 模型应该放在哪个 app，以及现有用户模型的关系"
Claude 会阅读代码并输出分析报告，不做任何修改

Step 3 - 规划实现方案（Plan Mode + Opus 模型）
输入 /model 切换到 Opus（能力更强的模型）
提问："设计用户消息通知功能的完整实现方案，包括 models、views、urls、signals，考虑站内信+邮件双通道"
Claude 输出完整设计方案，确认无误后再执行

Step 4 - 分模块执行（Auto-Accept 模式）
切换到 Auto-Accept 模式，分模块执行：
"先创建 Message 模型，包含 sender、receiver、title、body、is_read、channel 字段"
"然后创建 signal 处理器：当 Message 保存时，如果 channel=email 则调用 send_mail()"
每完成一个模块，用 /clear 清理上下文，再开始下一个模块

Step 5 - 性能审查（Plan Mode 回顾）
切回 Plan Mode："审查我新增的代码，检查 N+1 查询问题、缺少索引的字段、事务处理是否完整"
Claude 会指出：receiver 字段缺少 db_index、批量通知时没有使用 bulk_create、邮件发送未做异步处理

Step 6 - 沉淀经验（记忆固化）
运行 /memory，写入本次开发关键经验：
"消息通知模块使用了 Django signal 进行解耦，邮件发送通过 Celery task 异步执行"
下次开发类似功能时，Claude Code 会自动参考这些记忆

关键心得：使用完整六步工作流后，一个以往需要 2-3 天的功能，现在半天即可完成高质量交付。核心不在于 AI 写了多少代码，而在于 Plan Mode 帮你避免了方向性错误。
```

**▌ 进阶技巧**

80% 的用户不知道的窍门：
- **Ctrl+B 后台任务**：编译、测试等耗时操作可挂到后台执行，用 Ctrl+T 查看进度，前台继续其他操作
- **Alt+V 粘贴截图**（Windows）：把 UI 截图发给 Claude 分析界面问题，无需文字描述
- **`/compact` 压缩上下文**：对话超过 50 轮后，用 `/compact` 将历史总结为摘要，释放上下文空间
- **`/doctor` 环境诊断**：遇到异常时先跑 `/doctor`，自动检查 API 连通性、Git 可用性等
- **Claude Code + Cursor 组合**：用 Claude Code 做架构规划和批量重构，用 Cursor 做逐行代码补全，两者互补

**▌ 选型对比**

| 决策维度 | 用 Claude Code | 用 Cursor | 用 GitHub Copilot |
|---------|--------------|----------|-----------------|
| 适合什么任务 | 完整功能开发、架构设计、项目级重构 | 日常编码、探需求、快速原型 | 代码补全、简单函数生成 |
| 不适合什么任务 | 逐行代码补全（非其设计目标） | 大型跨文件重构 | 复杂架构设计 |
| 学习成本 | 中（需掌握命令和模式切换） | 低（VS Code 风格） | 极低（IDE 自动补全） |
| 价格 | API 按量计费 / Pro 订阅 | $20/月 Pro | $10/月（个人版） |

### 2. 【Perplexity AI 深度使用指南：把搜索变成研究，让信息收集效率翻10倍】

> 📍 **导语**：每天面对海量信息，你还在用传统搜索引擎一页页翻结果、手动打开七八个网页阅读总结吗？2026 年，Perplexity AI 已经成为全球增长最快的 AI 搜索工具，月活超 3 亿。它直接返回带来源引用的综合回答，把"找信息"变成"问信息"。但大多数人只用了它 20% 的能力——Focus 模式、Spaces 研究空间、Pages 报告生成等功能才是真正的效率杀手。本文基于 AIEII 团队三个月深度使用经验，手把手拆解 Perplexity 从基础到高级的全部用法，并附上与国产 AI 搜索（秘塔AI）的全面对比。

---

**🛠 深度实操指南**

**▌ 工具速览**

Perplexity AI 定位为"AI 研究助手"而非"更好的 Google"——用户用自然语言提问，AI 同时搜索多个来源，阅读并理解内容后，返回带来源引用的综合回答。核心差异在于"谁来做阅读和总结的工作"——Google 给你链接（你自己读），Perplexity 给你答案（带引用）。定价：免费版每天可进行有限次 Pro 搜索；Pro 版 $20/月，解锁不限次 Pro Search、Spaces 研究空间、文件上传和 API 权限。Perplexity 也是行业内来源透明度最高的 AI 搜索工具，每个答案都标注 [1][2][3]，可一键跳转原文。

**▌ 核心功能场景化拆解**

场景一：**日常信息查询——自然语言搜索的威力**。传统搜索引擎要求你拆解关键词（"2026 Q1 全球 AI 融资 金额"），Perplexity 让你直接用口语化句子提问："2026 年第一季度全球 AI 领域融资情况如何？请按轮次和地区分类"。AI 会自动搜索、理解、聚合信息，返回结构化的回答，每条数据都附有来源编号。追问机制支持上下文连续对话，每轮追问都会触发新搜索。

场景二：**深度研究——Spaces 研究空间（Pro 版最被低估的功能）**。为每个研究项目创建独立 Space：上传参考文件（PDF、论文、链接）作为"知识基线"；设定系统提示词保持回答视角一致（如"请从产品经理视角分析"）；所有对话历史可回溯，研究成果持续积累。这对于行业研究、竞品分析、学术论文检索等场景极为实用。例如：创建一个"竞品分析"Space，上传所有竞品白皮书，设置提示词为"只关注定价策略和功能差异"，每次提问都在这个定向框架下进行。

场景三：**快速生成报告——Pages 一键出稿**。将搜索结果自动整理成结构化文章，含目录、小标题、引用标注和格式化输出。适合：准备晨会材料、撰写行业简报、生成技术调研文档。输入一个主题，30 秒就能拿到一篇可直接使用的初稿。

**▌ 实战工作流**

```
场景：假设你要用 1 小时完成一份"2026 年 Q2 AI Agent 开发框架选型报告"

Step 1 - 搭建研究框架（5 分钟）
创建 Space 命名为"AI Agent 框架选型 Q2"
设置系统提示词："你是一名资深 AI 架构师，请从生产可用性、社区活跃度、云原生支持三个维度分析"

### 3. 【Coze 扣子 2.5 实战教程：零代码搭建 AI 智能体，给每个 Agent 配一台云电脑】

> 📍 **导语**：2026 年 4 月，字节跳动旗下的 Coze（扣子）发布了 2.5 版本，这也许是今年以来国产 AI Agent 平台最重磅的更新。每个智能体被赋予了自己的"云电脑"（Ubuntu 2 核 4G）、"云手机"（Android 13）和独立邮箱——Agent 不再只是"聊天机器人"，而是一个有手有脚、能自主上网查资料、操作 App、执行脚本的数字员工。本文为你手把手拆解 Coze 2.5 的核心玩法，从零开始搭建一个能真正干活的 AI 智能体。

---

**🛠 深度实操指南**

**▌ 工具速览**

Coze（扣子）是字节跳动推出的一站式 AI Agent 开发与运营平台。2026 年 1 月升级到 2.0，定位从"对话式 AI 工具"升级为可长期规划、自主执行、跨平台协作的 Agent 平台。2.5 版本（2026 年 4 月）新增了云电脑、云手机、Agent World 平行协作平台三大关键能力。面向非开发者：零代码可视化拖拽搭建；面向开发者：支持 API 集成、自定义插件、多模型调度（豆包、DeepSeek、GPT 等）。收费模式：基础功能免费，云电脑/云手机按资源使用计费（具体价格尚未完整公布）。

**▌ 核心功能场景化拆解**

场景一：**零代码搭建工作流——从"白板"到"自动化流水线"**。这是 Coze 最核心的能力。你不需要写一行代码，通过拖拽即可搭建完整的 AI 工作流：输入节点（接受用户提问）→ 大模型节点（调用豆包/DeepSeek 等模型处理）→ 知识库节点（检索企业文档）→ 代码节点（执行 Python 脚本）→ 条件判断节点（根据结果分支）→ 输出节点。每个节点可视化配置，流程一目了然。

场景二：**云电脑——Agent 真正有了"手"**。这是 Coze 2.5 最令人 WOW 的功能。每个 Agent 拥有一台 Ubuntu 云电脑（2 核 4G），内置浏览器、文件系统和终端。Agent 可以自主打开网页浏览器访问目标网站获取实时信息；将结果保存到文件系统（跨对话持久化）；用终端执行 Python 脚本进行数据处理。例如：创建一个"每周竞品价格监控 Agent"，它会每周自动打开竞品官网、抓取价格、写入表格、生成对比报告发送到你邮箱——全程无需人工干预。

场景三：**云手机——Agent 能像人一样操作 App**。2.5 版本为每个 Agent 配备了 Android 13 云手机（2vCPU + 6GB 内存 + 45GB 存储），Agent 可以像真人一样在 App 界面中点击、滑动、输入。典型场景：定期打开特定资讯 App 截图关键新闻并整理成摘要；在电商平台 App 中监控特定商品价格波动，达到预设阈值自动通知。安全设计上，重要操作（付款、修改设置）会暂停等待用户确认，用户可以随时通过屏幕推流查看 Agent 的实时操作。

**▌ 实战工作流**

```
场景：假设你要搭建一个"AI 日报自动生成员"——每天早上 9 点自动收集行业资讯并生成日报

Step 1 - 创建智能体（5 分钟）
登录 Coze 官网 (coze.cn)，点击"创建智能体"
命名为"日报小助手"，描述填入："每天早上 9 点自动搜集 AI 行业新闻，整理为日报格式发送至邮箱"
选择模型：推荐使用豆包 Pro（中文理解好，性价比高）

Step 2 - 配置工作流核心逻辑（20 分钟）
拖拽构建以下流程：
① 定时触发节点：设置 Cron 表达式 "0 9 * * *"（每天早上 9 点）
② 云电脑上网节点：打开 3-5 个目标资讯站（如 36氪、机器之心、TechCrunch），截取当日首页头条
③ 大模型处理节点：提示词设为"将以下新闻整理为日报格式，包含：标题、一句话摘要、来源链接。按重要程度排序。用中文输出"
④ 代码节点：用 Python 将结果格式化为 HTML 邮件模板
⑤ 邮件发送节点：通过 Coze 内置邮件功能发送到指定邮箱

Step 3 - 配置知识库（10 分钟）
上传背景知识：你的行业领域关键词、关注的公司名单、竞品名单
设置提示词："优先关注与[你所在行业]相关的新闻"

Step 4 - 测试和调试（15 分钟）
点击"预览"进行测试
输入测试指令："现在立即执行一次日报生成"
检查输出结果：标题是否吸引人？摘要是否准确？来源链接是否可访问？

**▌ 进阶技巧**

最能拉开差距的进阶操作：
- **云电脑 + 云手机双模式并行**：云电脑适合网页端数据抓取和分析；云手机适合 App 端操作和监控。复杂任务可两者协同——云手机截取 App 数据，传给云电脑进行数据分析
- **MCP 工具集成**：Coze 2.5 支持 MCP（Model Context Protocol）工具集成，可以接入高德地图、企业微信、飞书等外部服务的 MCP 接口，让 Agent 拥有"调用真实 API"的能力
- **多模型调度**：同一个工作流中，简单任务调用低成本模型（如豆包 Lite），复杂分析任务切换深度模型（如 DeepSeek-R1），按需分配成本最优
- **Agent World 协作**：如果任务足够复杂，可以创建多个 Agent 组成"团队"，一个负责采集数据、一个负责分析、一个负责出报告，Agent 之间通过 Agent World 平台自动协作
- **与飞书深度联动**：企业用户可将 Coze Agent 接入飞书，实现"@机器人 帮我查一下上季度销售数据"等办公场景自动化
