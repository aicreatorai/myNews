- **最让人 WOW 的功能**：2.5 版本 Agent 拥有独立邮箱地址——Agent 可以自主接收邮件、分析内容、回复邮件，不需要人工中转。这是迈向"AI 打工人"的关键一步。

**③ 实战工作流**

```
场景：假设你是一个独立 iOS 开发者，需要做一个自动收集 App Store 用户评价并分析的工具。

Step 1: 进入 Coze 官网 → 创建新 Agent → 命名为「评价分析师」
Step 2: 在"知识库"中上传产品功能说明文档 → 让 Agent 理解你的 App 是做什么的
Step 3: 在"技能"中添加「App Store Connect 插件」→ 配置 API Key（Coze 官方支持）
Step 4: 设置「长期计划」：每天早上 9:00 拉取最新用户评价 → AI 按"Bug报告/功能建议/好评"分类 → 生成分析摘要 → 发送到你的飞书
Step 5: 在"工作流"中配置：每天自动运行一次，不需要手动触发

关键心得：Coze 2.5 的"长期计划+邮箱"组合意味着 Agent 可以成为真正的"数字员工"——你只需要定义任务，剩下的 Agent 自主完成。独立开发者一人能管 3 个 App 的客服。
```

**⑤ 进阶技巧**

- Coze 2.5 的"AgentWorld"功能：可以创建多个 Agent 并让它们互相协作（如：一个 Agent 收集资料，另一个 Agent 分析，第三个 Agent 输出报告）。
