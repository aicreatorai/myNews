### 3. 【MCP协议实战：30分钟搭建一个"本地文件搜索AI助手"】

> 📝 **导语**（92字）：MCP（Model Context Protocol）是Anthropic发布的开放协议，让AI模型能统一调用外部工具。本文实战：用MCP协议，让Claude Desktop能搜索本地文件（无需手写插件代码），30分钟完成搭建。

**🧠 深度报道**

**▌ 它是什么？**

MCP协议 = "AI世界的USB-C接口"。传统方式：每个AI应用（Claude、GPT、Gemini）需要为每个外部工具（文件系统、GitHub、数据库）写独立的集成代码 → N个AI应用 × M个工具 = N×M个集成。MCP方式：工具提供方实现一次MCP Server，所有支持MCP的AI应用都能直接用 → N + M个实现。

**核心概念**：
- **MCP Server**：暴露工具/数据源的程序（如FileSystem MCP Server，提供"读文件""写文件""列表目录"工具）。
- **MCP Client**：运行在AI应用中的客户端（如Claude Desktop内置MCP Client），负责连接MCP Server、调用工具。
- **传输层**：MCP支持两种通信方式——stdio（本地进程通信，低延迟）、HTTP+SSE（远程通信，适合云部署）。

**实战：让Claude Desktop能搜索本地Markdown文件**（完整步骤）：

```bash
# 步骤1：安装Claude Desktop（已支持MCP）
# 访问 https://claude.com/download，下载macOS版本
# 安装后登录（需Anthropic账号）

# 步骤2：安装FileSystem MCP Server（官方提供）
# 方式1：用npx运行（无需安装，推荐）
# 在Claude Desktop设置中添加MCP Server：
# 点击左下角"设置" → "Developer" → "Edit Config"
# 在配置文件中添加：
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/你的用户名/Documents"]
    }
  }
}
# 说明："/Users/你的用户名/Documents"是允许Claude访问的目录（可设置多个）

# 方式2：用Python实现自定义MCP Server（暴露"搜索Markdown文件"工具）
# 安装MCP Python SDK：
pip install mcp

# 创建 mcp_server.py：
from mcp.server import Server
from mcp.server.stdio import stdio_server
import oas

server = Server("md-searcher")

@server.call_tool()
async def search_markdown(query: str, directory: str) -> str:
    """搜索指定目录下的所有.md文件，返回包含query的行"""
    results = []
    for root, dirs, files in os.walk(directory):
        for file in files:
            if file.endswith(".md"):
                filepath = os.path.join(root, file)
                with open(filepath, 'r') as f:
                    for i, line in enumerate(f, 1):
                        if query.lower() in line.lower():
                            results.append(f"{filepath}:{i}: {line.strip()}")
    return "\n".join(results[:20])  # 最多返回20条

if __name__ == "__main__":
    import asyncio
    asyncio.run(stdio_server(server))
```

**关键技巧**（避免踩坑）：

1. **MCP Server的目录权限**：FileSystem MCP Server只能访问配置中指定的目录。若要访问多个目录，配置中添加多个`"args"`参数：`["-y", "@modelcontextprotocol/server-filesystem", "/dir1", "/dir2"]`。
2. **MCP Server的调试**：若Claude无法调用工具，检查`~/.claude/logs/mcp.log`（macOS）查看错误信息。
3. **自定义MCP Server的文档**：必须用Python类型注解（Type Hints）和docstring，Claude会根据这些信息生成工具调用参数。

    # 3行代码加载模型（自动处理量化、设备映射）
