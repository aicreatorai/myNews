### 1. 【n8n工作流自动化：连接300+应用，打造你的AI自动化引擎】

> 📍 **导语** n8n是2026年最热门的开源工作流自动化平台，支持可视化拖拽搭建复杂流程，集成300+应用和AI模型。它既能像代码一样精准构建，也能像拖拽一样快速上手，支持私有化部署，让技术团队灵活实现多步骤AI智能体自动化。本文将通过5个实战场景，手把手教你用n8n构建从数据抓取到内容生成的完整自动化工作流，无需编写一行代码。

---

**🛠 深度实操指南**

**▌ 工具速览**
n8n（发音n-eight-n）是一款开源工作流自动化工具，2026年被评为"AI落地开源三剑客"之一（与LangChain、Dify并列）。其核心价值：1）**可视化拖拽**：通过节点拖拽连接，构建复杂工作流（类似Zapier但更强大）；2）**300+集成**：支持数据库（MySQL、PostgreSQL、MongoDB）、SaaS（Notion、Slack、GitHub）、AI服务（OpenAI、Claude、Hugging Face）；3）**AI Agent支持**：内置AI Agent节点，可调用LLM进行智能决策；4）**私有化部署**：支持本地、云端、Docker部署，数据完全可控；5）**代码灵活**：支持JavaScript/Python代码节点，兼顾灵活与效率。n8n提供免费开源版和付费云版（$20/月）。

**▌ 核心功能场景化拆解**
n8n的核心能力：1）**触发器（Triggers）**：定时触发（Cron）、Webhook触发、应用事件触发（如GitHub新PR）；2）**数据处理**：HTTP请求、数据转换（JSON/XML）、条件分支、循环；3）**AI集成**：调用OpenAI API生成文本、调用Stable Diffusion生成图片、调用语音API合成语音；4）**错误处理**：重试机制、失败通知、日志记录；5）**子工作流**：将复杂流程模块化，提高复用性。典型场景：新闻聚合机器人、AI自动摘要、数据定时统计、RAG知识库自动更新、社交媒体自动发布。

**▌ 实战工作流**
**场景：构建"AI驱动的科技新闻聚合与摘要系统"**

**目标**：每天自动抓取Hacker News和Reddit热门科技新闻，用AI生成中文摘要和点评，推送到Slack频道和企业微信。

**步骤1：安装与初始化**
- 方案A（本地开发）：`npm install n8n -g && n8n start`
- 方案B（Docker部署）：`docker run -it --rm --name n8n -p 5678:5678 -v ~/.n8n:/home/node/.n8n n8nio/n8n`
- 方案C（云部署）：注册n8n.cloud，直接使用云端版本（€20/月）
- 访问`http://localhost:5678`，创建账号并登录
- 推荐：生产环境用Docker部署，数据持久化到 volume

**步骤2：创建工作流与触发器**
- 点击"New Workflow"，命名为"科技新闻聚合与推送"
- 添加触发器：选择"Schedule Trigger"
  - 模式：Every day
  - 时间：09:00（北京时间）
  - 时区：Asia/Shanghai
- 添加节点：Set（设置全局变量）
  - 定义：`{{$now.format('YYYY-MM-DD')}}` 作为日期变量
  - 定义：`tech_news` 作为输出数组

**步骤3：抓取多源新闻数据**
- **数据源1：Hacker News**
  - 添加节点：HTTP Request
  - Method：GET
  - URL：`https://hacker-news.firebaseio.com/v0/topstories.json`
  - 添加节点：Split Out（拆分前10个ID）
  - 添加节点：HTTP Request（循环）
    - URL：`https://hacker-news.firebaseio.com/v0/item/{{$json.id}}.json`
  - 添加节点：Filter（过滤）
    - 条件：score > 100（只保留热门新闻）
  
- **数据源2：Reddit（r/technology）**
  - 添加节点：HTTP Request
  - Method：GET
  - URL：`https://www.reddit.com/r/technology/hot.json?limit=10`
  - Headers：User-Agent: "n8n-bot/1.0"
  - 添加节点：Code（JavaScript）
    - 提取title、url、score、selftext
  
- **数据源3：Twitter/X（可选）**
  - 添加节点：Twitter Trigger（需配置Twitter API）
  - 关键词：#AI #Tech #Programming
  - 限制：10条/天

**步骤4：数据清洗与去重**
- 添加节点：Merge（合并多源数据）
  - 模式：Append
- 添加节点：Code（JavaScript）
  - 去重逻辑：根据URL或标题相似度去重
  - 排序：按score和评论数排序
  - 限制：保留前20条
- 添加节点：Set
  - 格式化输出字段：title、url、source、score、summary

**步骤5：AI生成摘要与点评**
- 添加节点：OpenAI（或Claude、通义千问）
  - Model：GPT-4o（速度快）或Claude Opus 4.7（质量高）
  - Prompt模板：
    ```
    你是一位科技新闻编辑，请将以下新闻标题和摘要翻译并总结为150字以内的中文摘要，并添加50字的点评（分析其技术价值或行业影响）。
    
    标题：{{$json.title}}
    原文摘要：{{$json.selftext || $json.text}}
    来源：{{$json.source}}
    
    输出格式：
    【摘要】...（100-150字）
    【点评】...（50字）
    ```
  - 高级设置：Temperature=0.7（平衡创意与准确）
- 添加节点：Code（JavaScript）
  - 解析AI输出，分离摘要和点评
  - 添加Emoji（📰 新闻、💡 技术、🚀 产品）

**步骤6：生成可视化内容（可选）**
- 添加节点：HTTP Request（调用数据可视化API）
  - 服务：QuickChart.io（免费）
  - 生成：新闻来源分布饼图、热度趋势图
- 添加节点：Google Drive（上传图表）
  - 上传到共享文件夹，生成公开链接

**步骤7：推送到多渠道**
- **渠道1：Slack**
  - 添加节点：Slack（Webhook）
  - 配置Webhook URL（从Slack App获取）
  - 消息格式（Markdown）：
    ```
    📰 *今日科技要闻*（{{$now.format('YYYY-MM-DD')}}）
    共筛选出 {{$json.length}} 条热门新闻
    
    *1. {{$json.title}}*
    {{$json.ai_summary}}
    🔗 [阅读原文]({{$json.url}})
    ---
    （循环输出前5条）
    ```
  
- **渠道2：企业微信**
  - 添加节点：HTTP Request（企业微信Webhook）
  - URL：`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY`
  - Body（JSON）：
    ```json
    {
      "msgtype": "markdown",
      "markdown": {
        "content": "## 今日科技要闻\n{{$json.title}}\n{{$json.ai_summary}}"
      }
    }
    ```
  
- **渠道3：邮件（可选）**
  - 添加节点：Send Email（SMTP）
  - 收件人：团队邮件列表
  - 主题：今日科技要闻（{{$now.format('YYYY-MM-DD')}}）
  - 内容：HTML格式（用Code节点生成HTML）

**步骤8：错误处理与通知**
- 添加节点：Error Trigger（全局）
  - 触发条件：任何节点失败
- 添加节点：Slack（发送错误通知）
  - 频道：#tech-alerts
  - 消息：⚠️ 新闻聚合工作流执行失败，错误：{{$json.error.message}}
- 添加节点：IF（条件判断）
  - 条件：如果今日新闻数量 < 5，发送警告通知

**步骤9：测试与激活**
- 点击"Execute Workflow"手动测试
- 检查每个节点的输出（点击节点→"Output"）
- 常见问题排查：
  - API限流：添加"Wait"节点（延迟1秒）
  - 数据格式错误：用"Code"节点调试
  - AI输出不稳定：优化Prompt，添加Few-shot示例
- 确认无误后，点击"Activate"启用自动运行
- 监控：在n8n仪表盘查看执行历史（Execution History）

**实战技巧与最佳实践**：
1. **调试技巧**：在每个关键节点后添加"Set"节点，打印中间结果；使用"Pin Data"固定测试数据
2. **性能优化**：使用"Merge"节点并行处理多源数据；避免循环内调用AI（成本高），改为批量调用
3. **成本控制**：AI API按token计费，摘要控制在150字以内；使用缓存（Redis节点）避免重复调用
4. **安全存储**：API Key存储在n8n的Credentials中，不要在代码中硬编码；使用环境变量
5. **版本管理**：n8n支持工作流版本控制（Git集成），每次修改后提交
6. **扩展思路**：添加"用户反馈"节点（Slack投票），根据反馈优化筛选算法；集成RSS输出，生成个人博客

**▌ 进阶技巧**
1. **子工作流复用**：将"AI摘要生成"封装为子工作流，其他工作流可调用；2. **与LangChain集成**：n8n支持LangChain节点，可构建复杂的AI Agent（如RAG问答系统）；3. **Webhook对外服务**：用Webhook触发工作流，将n8n变为API服务（如"POST /summarize"触发摘要生成）；4. **数据持久化**：将工作流执行结果存储到数据库，用于审计和分析；5. **多Agent协作**：构建多个专用Agent（爬虫Agent、摘要Agent、发布Agent），通过消息队列协调。

### 2. 【Midjourney v7提示词实战：从堆砌关键词到高信息密度短句】

---

**🛠 深度实操指南**

**▌ 工具速览**
Midjourney v7是2026年最强的AI绘画模型，在照片级真实感、复杂场景构图、风格一致性上领先竞品。核心升级：1）**Omni Reference**：取代失效的--cref，实现角色一致性（同一角色在不同场景保持外观）；2）**--sref优化**：风格参考更精准，可指定多张参考图；3）**中文理解提升**：可直接用中文提示词生成（但建议中英文混合）；4）**分辨率提升**：默认生成2048×2048，支持--hd模式（4096×4096）；5）**速度提升**：v7比v6快30%，Turbo模式更快。Midjourney通过Discord机器人使用，需订阅（$10/月基础版）。

**▌ 核心功能场景化拆解**
Midjourney v7提示词的核心要素：1）**主体描述**（Subject）：清晰描述画面主体（如"一个亚洲女性"）；2）**环境与动作**（Environment & Action）：主体所处的环境和正在做的事（如"在东京街头散步"）；3）**视觉风格**（Style）：艺术风格、摄影师、电影风格（如"赛博朋克风格、王家卫电影"）；4）**技术参数**（Parameters）：--ar（宽高比）、--v（版本）、--s（风格化强度）、--q（质量）；5）**负面提示**（Negative Prompt）：用--no指定不想要的元素（如--no blurry, distorted）。v7的提示词公式：**短句描述 + 风格参考 + 技术参数**。

**▌ 实战工作流**

**▌ 实战工作流**
**任务：用ZCode 3.0 + GLM-5.2开发一个微服务电商系统**

**步骤1：环境准备**
- 注册智谱AI开放平台（open.bigmodel.cn），获取API Key
- 下载ZCode 3.0（zcode.zhipu.ai），安装并登录
- 配置模型：选择GLM-5.2（如需高速，选择GLM-5.2-Turbo）

**步骤2：项目初始化**
在ZCode中输入需求：
