### 3. 【Ollama实战：在大模型时代，本地部署AI模型的"瑞士军刀"】

> 📍 **导语**：OpenAI发布GPT-5.5-Mini蒸馏模型权重后，本地AI部署再次成为热点。Ollama作为最流行的本地AI模型部署工具，2026年6月新增了对MoE模型、多GPU分布和MCP Server的原生支持。本文分享用Ollama在消费级硬件上部署开源模型的完整工作流。

---

**🛠 深度实操指南**

**▌ 工具速览**
Ollama（ollama.ai）是2026年最受欢迎的本地AI模型部署工具，2026年6月发布v0.8版本。新增：MoE模型原生支持、多GPU自动分布（最多8张）、MCP Server集成、Ollama Web UI 2.0。支持的模型：Llama 4系列、DeepSeek V4、Qwen3、Gemma 3等100+模型。免费开源。

**▌ 实战工作流**
```bash
# 安装Ollama
curl -fsSL https://ollama.ai/install.sh | sh

# 部署GPT-5.5-Mini（OpenAI蒸馏模型，30B，INT4量化约15GB）
ollama pull gpt-5.5-mini:q4_K_M
ollama run gpt-5.5-mini:q4_K_M

# 部署MCP Server（让本地模型调用外部工具）
ollama mcp install mcp-server-search  # 搜索工具
ollama run gpt-5.5-mini "搜索2026年诺贝尔奖得主并总结"

# Ollama Web UI
open http://localhost:3000  # 浏览器访问本地AI聊天界面
```

| GPU支持 | 自动单/多卡 | 手动配置 | 自动多卡 |
