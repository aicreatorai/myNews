**▌ 选型建议**

**选择Flutter的场景**：
- 需要高性能图形渲染（如直播、视频编辑）
- 需要覆盖Web+移动+桌面全平台
- 团队愿意投入Dart语言学习

```yaml
# Flutter 4.0 跨平台配置
flutter:
  # 一套代码覆盖6个平台
  platforms:
    android:
      renderer: impeller
    ios:
      renderer: impeller
    web:
      wasm: true
    windows: true
    macos: true
    linux: true
```

**选择React Native的场景**：
- 团队已有React/前端技术栈
- 需要快速验证MVP和迭代
- 对原生模块访问要求高

```json
// react-native.config.js - RN新架构配置
{
  "react-native": {
    "newArchEnabled": true,
    "fabric": true,
    "turboModules": true,
    "hermes": {
      "enable": true,
      "strictMode": true
    }
  }
}
```

**选择Compose Multiplatform的场景**：
- 团队已使用Kotlin/Android技术栈
- 需要Android+iOS双端统一UI
- 希望逐步将现有Android应用扩展到其他平台

```kotlin
// Compose Multiplatform 跨平台代码
@Composable
fun GreetingView(name: String) {
    // 同一份代码，在Android和iOS上渲染一致
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
            text = "Hello, $name!",
            style = MaterialTheme.typography.headlineMedium
        )
        Spacer(modifier = Modifier.height(8.dp))
        Text(
            text = "Welcome to Compose Multiplatform",
            style = MaterialTheme.typography.bodyLarge,
            color = MaterialTheme.colorScheme.onSurfaceVariant
        )
    }
}
```
