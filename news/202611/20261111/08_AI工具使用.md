### 1. 【Claude Code 高频工作流：终端里的 AI 副驾】

> 📍 **导语**：Claude Code 是 Anthropic 的终端 AI 编程助手，能直接读写项目文件、跑命令、操作 Git。它不像聊天工具那样来回粘贴代码，而是把一句需求变成可运行改动。配合 Opus 5.5 默认模型、1M 上下文与 MCP 协议，它成为把想法落到代码的最短路径。

---

**▌ 它是什么？**

Claude Code 是什么？它本质上是一个"住在你终端里的编程智能体"。与网页版对话工具不同，它拥有对项目文件的真实读写权、对命令行和 Git 的直接操作权，以及可插拔的外部工具调用能力（通过 MCP 协议）。你用自然语言说"给注册表单加上邮箱校验"，它会自己找到相关组件、修改文件、跑测试，并把改动汇报给你。免费方案不包含它，需 Pro 及以上付费套餐或 API 账户；在 macOS、Linux、Windows 的终端、VS Code、JetBrains、桌面端与网页端都能运行，默认模型为 Opus 5.5，也支持 Sonnet、Haiku 等切换。

**▌ 它解决了什么问题？**

它解决的核心痛点是"AI 写代码只停留在对话里"。过去用聊天工具辅助编程，你得把代码复制进去、再把结果粘出来，上下文割裂、容易出错。Claude Code 把这一环打通：它直接工作在项目里，理解整个代码库结构后再动手，避免"改了 A 漏了 B"。它还解决了多步骤任务无人把控的问题——通过 Plan 模式先出方案、你确认后才改文件，配合 /review、Hooks 自动触发审查，让 AI 的每一步都可控、可回滚，把"自动化"和"安全感"同时给到开发者。

**▌ 核心原理拆解**

Claude Code 的底层原理可以拆成三层。第一层是"项目感知"：它不是把整块磁盘上传，而是在你发起请求时按需搜索、读取相关文件，结合 CLAUDE.md 里你写的命令与规范，在 1M token 的上下文窗口里构建对当前项目的理解。第二层是"工具调用循环"：模型先生成计划，再依次调用编辑文件、运行 shell、执行测试等工具，每一步的结果反馈回上下文，形成"思考—行动—观察"的闭环，直到任务完成或被你叫停。第三层是"权限与安全边界"：通过 Shift+Tab 切换 Manual（只读取、改文件前征求同意）、AcceptEdits（自动改工作区文件）、Auto（自主运行）等模式，把"AI 能做什么"交给你掌控；再叠加 MCP 协议，让它能安全连接 GitHub、Jira、数据库等外部系统。值得强调的是 /compact 与 /clear 的上下文管理原理——长会话里用 /compact 把对话压缩成摘要以节省 token，换到无关任务用 /clear 彻底清空，这背后是提示词缓存约 60 分钟失效的机制；而 /rewind 则能回退到检查点，把"试错"变成低成本探索。理解这套原理，你就不会把它当成"更聪明的补全框"，而是当作一个可被重新组装的运行时。

**▌ 动手验证**

动手前先确认已安装：在终端执行 `curl -fsSL https://claude.ai/install.sh | bash`（macOS/Linux），Windows 用 PowerShell 的 `irm https://claude.ai/install.ps1 | iex`，装完跑 `claude --version` 验证。进入项目目录执行 `claude`，首次会打开浏览器登录。验证一个真实工作流：① 先让 Claude 读代码——输入"概括这个代码库的技术栈与目录结构"，确认它能正确识别；② 用 `/plan` 进入计划模式，输入"给登录模块加邮箱格式校验"，看它是否先调研再给方案；③ 确认方案后让它实现，每改完一个文件要求它运行 `npm test` 验证；④ 用 `/review` 让它对本次改动做自检，再用 `git diff` 人工核对。把常用流程写成自定义命令也很容易：让 Claude 创建 `/repo` 命令，执行后显示当前 Git 分支和最近三次提交，重启 Claude Code 即可在任意项目调用，验证"重复描述→一条命令"的提效。

**▌ 对比与选型**

| 决策维度 | Claude Code | Cursor | Aider |
|---------|-----------|--------|-------|
| 运行位置 | 终端/IDE/网页 | IDE 内 | 终端 |
| 上下文来源 | 项目文件+MCP | 索引库 | Git 差异 |
| 自主程度 | 高，可跑测试 | 中，编辑为主 | 高，偏脚本 |
| 上手成本 | 中 | 低 | 中 |

选型上：想让 AI 真正"动手改项目并跑测试"，优先 Claude Code；若只想要顺手的补全与聊天，Cursor 更轻；追求纯命令行批量改造，Aider 更专。

### 2. 【Gamma 一键成片：把文档秒变专业 PPT】

> 📍 **导语**：Gamma 是一款 AI 演示文稿工具，输入主题或粘贴文档，它能在几分钟内生成带排版、配图和图表的专业幻灯片。它用灵活的"卡片"替代死板幻灯片，把从空白页到成稿最慢的环节压缩掉。最近官方强化了提示词直出、导入 Markdown 与高保真互转能力，成为周报、路演、培训的效率利器。

---

**▌ 它是什么？**

Gamma 是什么？它是一个把"想法或文档"直接变成演示文稿、网页和长文档的 AI 创作平台。与传统 PPT 软件不同，Gamma 的基本单位是"卡片"——比固定幻灯片更灵活，可承载不同布局与内容。你可以用三种方式启动：粘贴已有文稿、从大纲开始、或直接用一句话描述需求让 AI 生成内容加设计。免费档即可使用，重度用户可选约 10–20 美元/月的订阅。它支持导出为 PPTX、PDF、Google Slides 与网页链接，也能直接在线演示。

**▌ 它解决了什么问题？**

它解决的是"做 PPT 太慢、设计门槛高"的老问题。传统流程要先想结构、再找模板、手调每页排版，一份周报常常耗掉数小时。Gamma 把最耗时的"从空白到结构化初稿"交给 AI：你只管提供内容，它负责分章节、配版式、加图表。它还解决了"内容准确 vs 美观"的取舍——AI 设计通常达标，你只需把精力放在 20% 需要精修的关键页上。对不擅长排版的人，它相当于随身带了位设计师。

**▌ 核心原理拆解**

Gamma 的生成原理分为四步。第一步"内容理解"：你粘贴的文本或大纲会被解析成带层级的结构，AI 据此判断该分成几页、每页放什么。第二步"结构提案"：它给出幻灯片数量、内容分布与顺序的预览，让你在生成前调整——这一步把"返工"前置，省下后期修改时间。第三步"设计与排版"：基于所选主题（色彩、字体、间距一套设定贯穿全篇），用卡片布局自动生成每页视觉，并可在卡片内继续让 AI 扩写、精简或改写。第四步"精炼与导出"：你逐卡审核，用"Polish"按钮整体优化文案，再导出。其关键在于"前端加载优先"——AI 对靠前的输入权重更高，所以把最重要的点放前面效果更好；同时它保留人工编辑权，任何卡片都能直接改文字、换布局、加真实数据。理解这套原理，你就能用"清晰结构+具体约束"喂出更准的稿子，而不是把 AI 当黑箱。

**▌ 动手验证**

动手做一个销售周报：① 打开 gamma.app 注册（支持邮箱/Google/Microsoft），点 Create；② 选择"粘贴内容"，把上周 Excel 的销售数据要点粘进去，主题写"Q2 销售复盘，面向管理层，需要数据图表"；③ 在结构预览里把 5 页拆成封面、本周亮点、数据解读、问题、下周计划，合并冗余页；④ 选"商务"主题，生成后逐卡检查——把"约增长 30%"替换成真实数字；⑤ 点任意卡片用"Highlight 让 AI 改写这页文案"验证润色效果；⑥ 导出 PPTX 给同事。验证效率：一位销售经理实测把 5 小时手工压到 30 分钟。进阶：导入 .md 文件直接生成、用品牌色自定义主题、复制链接让同事在线预览。

**▌ 对比与选型**

| 维度 | Gamma | 百度文库AI | Canva |
|------|-------|-----------|-------|
| 输入方式 | 文档/大纲/提示词 | 文档问答 | 模板拖拽 |
| 产出形态 | 卡片式可编辑 | 文档+PPT | 固定画布 |
| 数据图表 | 中等 | 弱 | 强 |
| 中文体验 | 一般 | 好 | 好 |

选型：要"文档秒变可讲稿"选 Gamma；要中文文档深度处理选百度文库 AI；要精修平面设计选 Canva。

### 3. 【Monica 沉浸式翻译：外文网页双语对照读】

> 📍 **导语**：Monica 是一款常驻浏览器与桌面的多模型 AI 助手，集聊天、写作、总结、翻译于一身。它的网页翻译把外文段落直接以"原文在上、译文在下"呈现，免去频繁切标签页。最近官方强化了多引擎与场景专家模式，配合术语表，让专业文献、社媒、邮件的翻译都更贴合语境。

---

**▌ 它是什么？**

Monica 是什么？它是一个安装在 Chrome、Edge 等浏览器的扩展，也有 Windows、macOS、iOS、Android 独立应用，背后聚合了 OpenAI、Anthropic、Google 等多家模型，一个账号即可调用。核心交互是按 Cmd+M（Mac）或 Ctrl+M（Win）呼出侧边栏，在任何网页选中文字即可翻译、解释或总结。免费档每天约 40 次基础模型额度，进阶模型与智能体按订阅额度计算。它还能做 PDF 双语翻译、YouTube 带时间戳总结、多模型并排回答。

**▌ 它解决了什么问题？**

它解决的是"读外文网页时割裂、低效"的痛点。传统翻译要把段落复制到另开工具、再切回对照，思路常被打断。Monica 的沉浸式翻译把译文直接嵌在原文下方，段落一一对齐，读起来像读双语书。它还解决"通用翻译不够专业"的问题——切换 Gemini、GPT、Claude 等引擎，或启用学术论文、科技、邮件等场景专家模式，配合术语表让专业词不被误译。对需要大量查阅海外资料的职场人，它是低成本的信息平权工具。

**▌ 核心原理拆解**

Monica 的翻译原理建立在"多引擎路由 + 上下文注入"上。第一层是引擎选择：它把请求可路由到传统翻译引擎（谷歌、微软、DeepL）或大模型（Gemini、GPT、Claude），大模型因理解整句语义，对意译、口语化表达更自然。第二层是沉浸式渲染：扩展在网页 DOM 中为每个段落注入译文节点，置于原文之下并保留原结构，刷新后自动重排，做到"不切页对照"。第三层是场景专家：选择 AI 模型时，Monica 会预设一套 system 指令（如"你是学术论文翻译专家，保留术语与引用格式"），把通用模型调成垂直风格。第四层是术语表与样式：术语表作为额外上下文注入，保证专有名词一致；显示样式（下划线、弱化、自定义颜色）通过 CSS 控制。理解原理后你会明白：联网模型更灵活但可能更慢，本地引擎更快更稳，专业文献应开"学术论文专家+术语表"，社媒段子用通用意译即可。

**▌ 动手验证**

动手配置双语对照：① 打开 monica.im 登录（GitHub 或 Google），左侧"扩展"找到"网页翻译"安装插件；② 点地址栏右侧"M"图标→设置→"翻译模式"选"沉浸式翻译"，布局方式勾"译文显示在原文下方"，保存并刷新；③ 打开英文站（如 news.ycombinator.com）验证每段下方是否出现中文；④ 进阶：设置里把"译文字体大小"设为 14px、行高 1.4–1.6，排除选择器填 `.ads-container,.comment-section` 避免评论区被翻；⑤ 读论文时切到"学术论文翻译专家"并加术语表验证专业词一致。快捷键：悬停段落按 Ctrl 翻译该段、再按恢复。验证隐私：敏感合同勿传外部模型。

**▌ 对比与选型**

| 维度 | Monica | 沉浸式翻译插件 | DeepL |
|------|--------|--------------|-------|
| 模型来源 | 多模型聚合 | 多引擎 | 自有引擎 |
| 场景专家 | 有 | 有 | 无 |
| 多模型并排 | 支持 | 不支持 | 不支持 |
| 免费额度 | 每日约40次 | 有 | 有限 |

选型：想要"一个入口调所有模型+多模型对比"选 Monica；纯翻译轻量选沉浸式翻译插件；追求译文质感选 DeepL。

### 4. 【Coze Dify 零代码搭 AI 工作流不求人】

> 📍 **导语**：Coze（扣子）与 Dify 是国内最主流的两大零代码/低代码 AI 智能体搭建平台。你不用写复杂代码，用拖拽节点、配提示词、接知识库，就能做出能对话、能跑流程的 AI 助手，并一键发布到豆包、飞书、微信。最近官方加强了工作流与 Agent 节点，让"多角色协作生产内容"也成可视化操作。

---

**▌ 它是什么？**

Coze 是什么？它是字节旗下的 AI 智能体开发平台，提供可视化工作流画布、丰富插件、知识库与一键多渠道发布。Dify 又是什么？它是开源、偏开发者的 LLMOps 平台，同样支持工作流，但额外提供代码节点、私有化部署与 API 优先。两者都把"大模型 + 提示词 + 工具/知识库 + 流程编排"封装成可拖拽的节点。对个人，Coze 更零门槛；对企业要私有化，Dify 更合适。

**▌ 它解决了什么问题？**

它解决了"造一个 AI 应用必须会写代码"的门槛。过去要做客服机器人或自动化工单，得自己接 API、写后端、管向量库，周期以周计。现在用 Coze/Dify，非工程师也能在半小时内搭出可用智能体：上传公司制度 PDF 做知识库，拖出"意图识别→FAQ 检索→工单收集"三个节点，发布即用。它尤其解决了"模型答非所问"——通过先做意图分支、再让对应节点处理，把自由发挥变成可控流程，大幅降低幻觉与跑题。

**▌ 核心原理拆解**

这类平台的原理是"有向图工作流 + 大模型节点"。第一，画布上的每个节点是一个可执行单元：开始/结束节点界定输入输出，LLM 节点承载提示词与模型，知识库节点做检索增强（RAG），HTTP/代码节点调用外部 API。第二，数据流沿连线传递：上一步的输出变量（如 product_name）成为下一步输入，形成"变量赋值—传递—合并"的管道。第三，RAG 原理是先把你上传的 PDF 切片向量化，用户提问时检索最相关片段，拼进提示词让模型"基于文档答"，避免瞎编。第四，Agent 节点让某个角色能自选工具——在 Dify 中给资料角色配读取内部资料的工具，再把它输出引用到写作节点，实现多智能体协作。理解后你会明白：工作流的价值不在"炫技"，而在把模糊任务拆成"有明确输入输出"的确定步骤，让 AI 可验证、可调试、可复用。

**▌ 动手验证**

动手搭一个电商文案助手（Coze）：① 登录 Coze，创建智能体，填写"电商文案助手"与人设提示词；② 新建工作流，拖出 开始→LLM（配置提示词："电商产品图，产品是{product_name}，风格{keywords}，高清摄影风，白底"，输出变量 product_image）→结束；③ 测试输入"女士真丝衬衫 / 通勤简约高级"，查看每节点输入输出验证文案与图是否符合；④ 发布为"技能"挂到智能体，再发布到豆包。Dify 版：建"工作流"应用，开始→文本生成（LLM）→HTTP/代码节点调文生图 API→变量合并→结束，并在流程中插"知识库检索"让文案先参考《品牌规范.pdf》。验证：用真实产品名跑一遍，确认输出结构稳定。

**▌ 对比与选型**

| 维度 | Coze | Dify | 扣子编程 |
|------|------|------|---------|
| 目标用户 | 零代码个人 | 开发者/企业 | 顺序流程 |
| 私有部署 | 弱 | 强 | 中 |
| 代码节点 | 无 | 有 | 无 |
| 发布渠道 | 豆包/飞书等 | API/自托管 | 平台内 |

选型：零基础做对话机器人选 Coze；要私有化与代码控制选 Dify；要确定性顺序流水线选扣子编程。

### 5. 【即梦 AI 文生图：用提示词与参考图做出电商级配图】

> 📍 **导语**：即梦 AI 是字节旗下的 AI 图像与视频生成工具，输入文字或参考图，十几秒就能产出高清画面，还能做局部重绘、扩图与无限画布。它最大亮点是中文文字渲染清晰、支持角色一致性库，适合电商主图、自媒体封面与短视频分镜。最近官方强化了参考图锚定与画布协作能力。

---

**▌ 它是什么？**

即梦 AI 是什么？它是字节跳动推出的生成式视觉创作平台，覆盖文生图、图生图、局部重绘、AI 扩图与视频生成。你可用抖音、剪映或手机号一键登录，新用户有每日免费额度。主界面分"AI 创作""我的作品""灵感广场"，在创作中选择文生图或图生图，设置画布比例（1:1、16:9、3:4）、数量、风格标签与负面提示词，约 10–20 秒生成四宫格图，再进编辑面板精修，最高支持 4K 导出，并可一键发到剪映做视频。

**▌ 它解决了什么问题？**

它解决的是"普通人也能产出专业级视觉"的难题。过去做电商主图要请摄影师、租棚、后期，成本高周期长；做封面要会 PS。即梦把这套流程压成"写提示词→生成→微调"，并专门攻克了传统 AI 生图"中文文字模糊"的痛点——能清晰生成含中文标题、标语、LOGO 的文字图，直接用于社媒配图。它还用"角色一致性库"解决多图人物脸崩的问题：上传多张同一人物照建库，后续生成保持五官服饰一致，满足 IP 与品牌需求。

**▌ 核心原理拆解**

即梦的生成原理是"扩散模型 + 提示词对齐 + 参考图控制"。第一，底层是文生图扩散模型：从噪声逐步去噪生成图像，模型对提示词里的细微差别（主体、光线、构图、风格）高度敏感，所以描述越准画面越贴合。第二，提示词到像素的对齐：它把你的文本编码为条件信号，引导去噪方向，使输出与命令精确对齐；中文文字渲染则靠专门训练的文字图层，避免乱码。第三，参考图锚定（image-to-image / 多参考）：上传参考图后，模型提取其人物样貌、构图、色调作为约束，你还可给参考图"分工"——一张管长相、一张管环境，避免一次性丢杂乱图致逻辑混乱。第四，无限画布与角色库：画布把多张素材同台摆放统一风格，角色库把同一人物特征向量化复用。理解原理后你会懂：提示词要"精准简短"而非越长越好，每次只改 1–2 个条件便于归因，参考图要清晰主体突出，否则生成质量会随参考图劣化。

### 6. 【剪映 AI 剪辑：字幕配音特效一条龙】

> 📍 **导语**：剪映（CapCut）是字节旗下的视频剪辑工具，内置一整套 AI 能力：一键成片、智能字幕、AI 配音、智能抠像、降噪与数字人。它把"导入素材到出片"最繁琐的环节自动化，让不会剪辑的人也能几分钟内产出带字幕、配音、特效的成片。最近官方在 PC 端强化了 4 机位与多时间线等专业能力。

---

**▌ 它是什么？**

剪映是什么？它是覆盖手机、PC、网页的免费视频剪辑软件，AI 能力深度嵌入每个环节。核心 AI 功能包括：一键成片（输入主题或素材自动剪）、智能字幕（语音转文字并同步）、AI 配音（文字转语音、音色克隆）、智能抠像（去背景）、人声分离与降噪、智能补帧与超清画质、文本朗读与数字人。PC 端还提供蒙版、关键帧、多机位、多时间线等专业工具，支持 NVIDIA RTX 50 系硬件加速导出。

**▌ 它解决了什么问题？**

它解决的是"视频制作门槛高、耗时长"的普遍痛点。过去加字幕要逐句听写、配音要录音棚、抠像要绿幕，普通人做一条口播视频要几小时。剪映把这些都变成一键：语音自动转字幕并批量改样式，文字一键变多种音色配音，人物自动抠出换背景。它还解决"素材零散难成片"——一键成片能按节奏自动匹配画面与 BGM，把 10 分钟素材压成 3 分钟精华。对自媒体、电商、政企宣传，它等于把后期团队装进了软件。

**▌ 核心原理拆解**

剪映的 AI 原理是"多模型流水线 + 非破坏性编辑"。第一，自动字幕靠语音识别（ASR）模型把音轨转成带时间戳的文本，再映射回时间轴，支持 30+ 语言、准确率超 98%，这是"所听即所显"的基础。第二，AI 配音是文本转语音（TTS）模型，提供多音色并可克隆原声，配合降噪模型先滤环境噪声再合成，听感更干净。第三，智能抠像用分割模型识别人像/物体边缘（含发丝级细节），生成透明通道；人声分离则把音轨拆成人声与背景声两个分支。第四，一键成片是"内容理解 + 节奏匹配"：模型先抽关键片段、理解语义，再用节拍检测把画面切点到音乐鼓点上。理解原理有助于你用对功能：字幕先自动再人工校生僻词，配音前先降噪，抠像后复制原视频底层用"变亮"混合补全发丝绿边——这些"AI 输出 + 手动精修"的组合，才是稳定出片的关键。
